## 3. 核心系统

### 3.1 真实擅长：证明链

每道题（格子）一条链，存在 `S.world.proof[题号]`，**不改引擎的格子颜色**。

| 步 | 条件 | 得到 |
|---|---|---|
| 0 → 1 | 当天证明一次 | 铁锭 |
| 1 → 2 | 距上一步 ≥ 1 天，当天证明一次 | 金锭 |
| 2 → 3 | 距上一步 ≥ 3 天，当天证明一次 | 钻石；地块永久的条件 |
| 3 → 4 | 距上一步 ≥ 14 天，当天证明一次 | 地块附魔，不发材料 |

**当天证明一次 = 当天最前面的作答都对**（🔍 受连续再学习研究启发，不是同一机制）：固定题第 1 次；题型前 2 次（数字不同）；选择题前 3 次（防蒙）；要求快的题还要达到现有秒答标准（`E.needFast`）。

| 情况 | 结果 |
|---|---|
| 写错 | 第 3 步以前退一步，间隔从今天算；第 3 步以后不退。今天不再算 |
| 对但不够快 | 不进不退，今天不再算 |
| 当场再来一次 | 不算 |
| 偷看过 | 今天不再算 |
| 当天第 2 次起 | 不算 |
| 退一步再升回来 | 不重复发材料（`top` 记最高到过哪步）；孩子看到的方格按 `top` 显示，只增不减 |
| 记录里的日期在未来（改过系统日期） | 夹回今天，间隔重算，证明链不冻结 |

**和现有规则的关系**：`FAST_OUT` 可以让一道题 2 天到深红，中间没有隔 3 天，所以深红不能直接当真实擅长。证明链只读作答结果，不影响格子、错题、奖状。

**接入方式（门 6）**：每天的顺序定为：上次结算没跑的先补 `endOfPractice` → `pruneBound`（传全量题库）→ 排课和守护题 → 每次 `settle` 之后调 `onAttempt` → 练习日达标后 `endOfPractice`。守护题排在今天最前面（保证提前退出的孩子也答到；🔍 交错效果会弱一些）：没下架的走现有路径（模拟用 `session.inject` 验证过）；已下架的绕开 `picker` 和 `makeLive`，**不写引擎状态、不计 `addFast`、不进错题本**，只记证明和时间。

**回来次数的硬上限**：已下架的题为地块回来，**按天计，每道最多 4 天**（题型一天答 2 次也算 1 天）。满了不算学会：换一道没绑的题；换不了就去掉；绑定空了地块进迷雾，计入 14 天到期额度，等重新绑题，**绝不白给永久**。永久地块的绑定不再改动。两周复查单独算，每 14 天最多 1 次。

**模拟**（真实排课；真实起点 + 中等孩子，第 30 天；对错来自遗忘模型，是假设）：

| 怎么做 | 永久地块 | 第 3 步的题 | 说明 |
|---|---|---|---|
| 正常 | 40 [30–48] | 120 | 基线 |
| 每天多练 60 题 | 56 [51–63] | 141 | 加练证明了更多不同的题，**钻石和地块都会变多**。这是真实练习，代价是多一倍时间；同一道题当天刷多少次都不算 |
| 不会的题就偷看 | 43 [37–49] | 130 | 偷看过的题当天不算，靠偷看证明不了；会的题照常算，所以不比正常少（🔍 这个模型里偷看也算一次学习） |
| 全程乱点 | 1 [1–2] | 7 | 真实起点有不少题只差一步，碰巧写对（模型 5%）也算。180 天：真实起点永久 1 块、累计钻石 9；空白起点 0 块、0 钻石 |
| 同一块地每天答对 50 次（测试） | 第 5 天才永久 | | 规则下限 |

| 判定规则（隔 14 天不练还记得，中位） | 强 | 中 | 弱 | 弱孩子放行题数 |
|---|---|---|---|---|
| 累计答对 5 次 | 63% | 56% | 39% | 232 |
| 引擎深红 | 84% | 73% | 51% | 248 |
| **第 3 步（永久）** | 86% | **78%** | **62%** | **93** |
| **第 4 步（附魔）** | 92% | **84%** | **67%** | **75** |

**局限**：第 3 步只比深红略好，主要作用是放行更少；真正硬的是第 4 步。隔 5 天的版本（同一次模拟，真实起点）：90 天永久 58 块对 77，到期率 21% 对 16%，90 天深红不变；记忆提升在上一轮对照中只有 1–3 个百分点，这轮没有重报，所以不选。全部依赖遗忘模型。

### 3.2 地块状态机

```
迷雾（没拓过）
  │ 插旗（要旗；有可绑的题）
  ├─ 已学会的题攒够 3 分 ─────────────────────▶ 永久（不占临时名额）
  ▼
临时（绑 3 分，5 支火把）──绑定的题全到第 3 步──▶ 永久 ──全到第 4 步──▶ 附魔（永不退回）
  │ 火把烧完                                      ▲
  ▼                                               │
迷雾地块（建筑保留）──绑定的题全到第 3 步，免费───┘
  └─再插一面旗 ──▶ 临时（同一批题，建筑还在）
```

- **绑题**：3 分。固定题 1 分，题型 3 分。只绑孩子已经开始学、还没绑过地块的题，正在进行的优先。已学会的题**攒够 3 分**才换一块永久（第 2 版 1 分就能换，审查查出永久地块虚高），**减负时也一样**：减负只放宽临时地块（绑 2 分），不让永久变便宜。不足 3 分有三个来源：减负期的临时地块、换题后没有题可补、题库到头。题库到头时，已学会的题不足 3 分也换；**开放的题** 70% 以上学会且没有在等的地块时，地块直接给（分母是开放的全部题，不是看过的题）。没开放的题不挡路。换题按分，题型满额换回 3 分。模拟 180 天，中等孩子永久地块 112 块满 3 分、5 块不足、0 块空绑定。
- **练习日**：当天练满 5 分钟或题做完（沿用 v5 口径）。**只有练习日才开放世界**，也才可能烧火把。模拟：每天只答 30 题（约 3 分钟）就退出，够不上练习日，世界不开；答 50 题（约 5 分钟）可以。
- **火把**：5 支。

| 今天绑定的题 | 烧不烧 |
|---|---|
| 有前进 | 不烧 |
| 有答对（包括在等间隔的）或答慢 | 不烧，除非下面最后一条 |
| 只有写错 | 烧 1 支 |
| 没轮到（等间隔或配额满） | 不烧，除非下面最后一条 |
| 今天没来 | 不烧 |
| 14 天内已到期满 3 块（保险） | 最后 1 支不灭，优先于所有其他条 |
| 家长关了到期 | 不烧，也不计「练习日数」，再打开不会连烧 |
| 地块已超过 10 个练习日且今天没有前进 | 烧 1 支 |

  支数对照（真实起点 90 天，到期 ÷ 临时插旗）：3 支 18% / 42%（中 / 弱），5 支 16% / 36%，7 支 10% / 34%。选 5 支：Ben 说的 3–7 取中间，首次到期约在第 2 周，孩子能感受到又不频繁。
- **临时上限**：5 块；最近 14 天到期过 2 块，降到 3 块，新地只绑 2 分、7 支火把。提示写「临时地块已满」，不写数字。
- **守护题和复查题**：**复查排最前面**（最多 3 道），然后是绑在临时和迷雾地块上、够间隔的守护题（最多 8 道）；合计用时到 40 秒就停，全部计入 10 分钟。模拟平均 44 秒/天，单日最多约 1 分钟（一题没答完不打断）。复查必须排前面：排后面时被上限挡住，间隔拉长，主指标从中等孩子 71% 掉到 53%（实测）。
- **到期不扣任何东西**。家长可关到期。

### 3.3 材料、工具、方块

**账本**：简单余额。累计铁金钻由证明链算出，每步只发一次。世界不跨设备合并（§6.2），所以没有合并带来的刷和丢。性质测试保证：已放的钻石块 + 背包里的钻石块 + 余额 = 累计钻石。

| 材料 | 来源 | 用途 | 防通胀 |
|---|---|---|---|

**读法**：

- **弱孩子是最大风险**：到期率过半，最长 30 天（最差 81 天）没有新永久地块，这段只靠矿石和建造撑着。自动减负和频率上限已加，判停线见 §3.5。空空是哪一档不知道，要看第 1 期数据。
- **手写慢是第二风险**：秒答概率减半时，永久地块少近一半，到期率升到 42%；用时 ×1.5 时到期率 32%（40 秒上限在用时长的孩子身上挡掉更多守护题）。第 1 期先量真实秒答率。
- **题到头**：只有强孩子约 90–120 天证明到头；中等孩子第 180 天第 3 步 243/295，弱孩子约 118。三、四年级的题上线后缓解。
- 模拟里的孩子每天把材料花完、只盖普通方块，真实孩子攒着盖城堡，节奏会不一样。木头、煤、矿石后期有剩余，模拟没有花它们的路径，不代表通胀。
- 作答用时按宝石规则的样本估（5–8 秒一题，前 90 天日均答对约 60 题，后 90 天约 53），手写真实用时要回填。

### 3.6 和空空矿场打通：两本账，永不互换

**依赖** `~/01_业务/个人项目/空空矿场/docs/说明书-宝石规则.md`（写本文时第 6 版，还在变；**门 6 前要按最新版再对一次**）。宝石怎么算以它为准，它第十二节已写明和 v7「两本账，永不互换」。

| 物 | 来源 | 去向 |
|---|---|---|
| 线下珠子 | 完成仪式 | 无，不换任何东西 |
| 碎片和宝石 | 按宝石规则（答题得碎片，锻造台炼宝石） | 娱乐时间 |
| 矿石和锭 | 答对、证明 | 世界里合成和建造 |

**来源可以相同，去向永不交叉。** 世界时间不产生碎片和宝石，世界里花东西不影响宝石。

要对齐的五处（改对方文档要等那边确认）：

1. **矿石口径**：宝石规则第七节写「矿石照旧（答对就有、只累计、不能花）」，v7 上线后矿石可以花。解法：累计数（木箱）照旧只增，世界余额另算；宝石规则这句话到时改。
2. **守护题和碎片**：宝石规则「题做完就没了」是防线之一。**已下架的题以守护题回来时不给碎片**；没下架的按原规则（每题每天第一次作答）。接口：守护题和复查题的作答记录带 `x.guard = true`；`x.guard && 题已下架` 时不给碎片（宝石规则第十三节等这个名字加测试）。
3. **结算页**：宝石规则有「去锻造 / 再练一会 / 挑战」，v7 加「去世界」。一屏一个主动作：练习结束主按钮去世界，其余收成次要；领宝石 7 天内都能领。合并版式等宝石规则落地后定。
   **「挑战」两边不是一回事**：宝石规则的挑战是 5 道高难度题、用挑战券；世界的是 Boss，一天一次、不用券。实施时世界按钮写 Boss 名（如「挑战苔藓石人」），术语表分开写。
4. **合成入口**：家里的锻造台和熔炉（炼宝石）、世界的工作台（做工具和方块）是两个入口，孩子可能混。宝石规则已留话：世界上线后可以把入口放到工作台旁边。实施时一起放，名字保持不同。

配置要求沿用宝石规则：数学岛不能放进「学习应用」分组，否则在世界里盖房也加宝石。

- `C.exportText` 不用改，世界随存档整份导出。**整份导入 = 回到备份那一刻**，世界和格子一起回退，没有净增，所以刷不出东西。
- **合并导入：世界不做字段合并，也不比较谁大。** 本机世界**玩过**（插过旗或盖过东西）就不动，不管备份里的永久地块多多少；本机没玩过才接收备份里的世界。家长设置留本机的。结构不对的世界不接收。格子进度照旧合并，合并后按题补证明。（第 3 版按永久地块多少选一份，审查实测会静默丢掉当前世界：只要迁移，别的设备的世界就可能永久地块更多。）
- **整份导入**前把当前世界存到 `S.worldBak`，导入后家长区可以恢复一次。这条覆盖「换 iPad、从备份恢复」。
- 为什么：前两轮审查证明字段级合并能刷方块、丢东西，要修就得做事件日志。而两台设备本来就「进度各存各的」（`ios/release.sh`），不值得。**代价**：同一个孩子在两台设备上有两张地图，互不合并。所以主战场定 iPad（宝石也只在 iPad 算），要 Ben 确认空空手机上不玩世界。

**回滚**：旧代码不认 `S.world`，原样留在存档，格子数不变；升回来继续用，回滚期间火把不走。

**损坏恢复**：用 `S.worldBak`，**不用格子重新迁移**（下架题的第 3 步只在证明链里，重迁移会丢）。

**迁移测试**：规则层已有（下架直达、不覆盖、重复迁移、导入后补证明）。真实 v2 存档接入的测试在门 6。

**iPad**：内容随 `ios/release.sh` 同步，进度各存各的，手机和 iPad 是两张地图。宝石规则也只在 iPad 算，所以**主战场定 iPad**。

## 7. 异常处理

| 情况 | 处理 |
|---|---|
| 存不了进度 | 世界照常看，沿用提示条 |
| 数据损坏 | 沿用 v2 恢复流程；`S.world` 从 `S.worldBak` 恢复 |
| 切后台 / 来电 | 白天时间和作答计时都暂停 |
| 答到一半刷新 | 每题都存，回来「继续今天的探险」（原型已验证） |
| 横竖屏 | 沿用「把设备横过来」 |
| 跨午夜 | 探险中跨午夜按开始的日子算；世界里白天用完为止，新的一天要先探险 |
| 改系统日期 | 记录里的未来日期夹回今天，证明链不冻结；当天判定按日期存，来回改不清；练习日只往前走，来回改刷不到木头。**来回改能骗到间隔，但每步仍要答对**。iPad 靠空空矿场的时间锁（真机未验证），手机防不了 |
| 连点 / 误触 | 点地块走 click，不穿透弹窗；弹窗 300 毫秒内不响应；移动超过 16 像素算拖动；第二根手指忽略（接入时确认和 iPad 外壳的捏合缩放不打架）；放错可拆，方块退回 |
| 脚本出错 | 沿用全局兜底页 |
| 多标签页 | 沿用 v2 |
| 题下线或回来满 4 天 | 换一道没绑的题；换不了就去掉；绑定空了进迷雾（题下线的退旗），不给永久。题库列表为空或比历史最大值少 10% 以上时什么都不做：一定是传错了，**调用方必须传全量题库，不传过滤后的列表** |
| Boss 题池不足 3 道 | 不开挑战，提示这一带的题学会更多后可以挑战 |
| 手选难度后绑定题不开放 | 守护题照出（只这几道）；或家长关到期 |
| 全部题到第 3 步或没有可绑的题 | 看过的题都学会且没有在等的地块：插旗直接永久；否则提示明天学新题 |
| 地图拖远 | 有边界，有回家按钮 |

## 11. 取舍记录

- **俯视而不是侧视或 3D**：地图向外长一眼能看出来；手机横屏一屏放得下；成本和时长好控制。代价：比真正的方块游戏弱得多，**这是最大的产品风险**，所以第 0 期先让空空试。Minecraft 主玩法是第一人称，俯视只是地图道具，不能说「孩子不陌生」。
- **绑题由系统选**：让孩子选，他会挑最容易的。
- **矿石沿用答对就给**：差的日子也有收获；真实擅长只决定高级材料。
- **工具看累计**：第 1 版消耗钻石，盖城堡会把钻石镐永久锁死。
- **世界不合并**：见 §6.2。
- **慢答不烧火把**：第 2 版慢答 3 次后烧，模拟里秒答率一低到期率就很高；答慢的孩子其实会，不该丢地。
- **双语**：见 §4。
- **陷阱和捉弄人**：单机没有别的玩家，第 3 期可放路过的小怪掉进陷阱，先确认空空现在还爱玩这个。
