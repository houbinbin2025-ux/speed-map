# v2 改动说明（白话版）

## 改了什么
新做了一个**预览版**，地址是在原网址后面加 `v2/`。原来空空在用的网页一个字没动。
- **手写作答**：手机横过来，左边出题，右边手写板。写完停一下就自动判对错、记用时，不用大人在旁边。
- **第一次用先「认字」**：0–9 每个数字写 3 遍（约 2 分钟），之后按空空自己的笔迹认字，越用越准。
- **认不准时问一下**：弹出「你写的是 3 还是 8？」。两个选项只看笔迹像什么、不看答案；靠这一步认出来的题算写对，但不算秒答、方块不升级。
- **写错了**：显示正确答案，在淡色数字上描一笔就继续（或等 3 秒）。连着错时不再要求描。
- **错题本**：写错的题隔 1、2、4、7、15 天回来，每次写对过 1 关，过完 5 关算真会了。平时练习会自动带上到期的错题，每批 20 题里难题最多 8 题次，不会扎堆。
- **结束练习要长按 1 秒**；**家长区要长按齿轮 2 秒**（防孩子误碰）。家长区能看几天没备份、导出导入进度和笔迹、打开口答模式（家长陪着时用）。

## 可能影响什么
- 线上旧版：**不受影响**（根目录 `index.html` 与线上 0 行差异）。
- 空空的进度：预览版只**读**旧版进度，从不改写。预览里练的地图进度不算数，错题本和笔迹会留着；以后正式替换时，旧进度只搬一次过来。
- 必须一直用 **Safari 打开**，不要「添加到主屏幕」（两者存的数据互相看不到）。

## 还没验证的
- **空空真实笔迹的识别率**：电脑上用程序造的字认对 100%，但孩子的字更乱，要在你的 iPhone 上让空空写一批（建议 100 次）看家长区里「不用确认就认出」的次数。
- 手写限时（按校准时测到的写字速度算）松不松、0.9 / 1.5 秒自动提交会不会太快，都要看真人用了才知道。

## 怎么退回
- 不想要预览版：删掉 `v2/` 文件夹即可，旧版和旧进度都在。
- 以后正式替换后想退回：把根目录 `index.html` 换回 v1，旧进度原样保留在 `speedmap.v1`。

## 2026-10-26 真机反馈后的修复
- **题目被手写板挡住**：题目字号原来按整个屏幕宽度算，iPhone 横屏两侧有安全区，左栏变窄就溢出。改为放不下就按比例缩小。
- **两位数总弹「你写的是？」**：某一位两可时，如果其中一个候选正是答案要的数字、拼起来等于答案，就直接认对、不弹窗、可算秒答。两个候选都对不上答案时照常弹窗。代价：形近写错（5 写得像 6、答案正好是 6）会被判对，只在笔迹本来几乎分不清时发生。被定夺的那一位不学进模板，家长区识别率也不把它算作「认出」。
- **手机可能拿旧脚本配新页面**：脚本引用加版本号 `?v=N`，改脚本时一起加 1；新增测试检查页面调用的函数在脚本里都存在，且改了脚本没加版本号时测试会失败。

## 证据
- 自动测试 39 个全部通过（10-26 起）（`npm test`）：题目编号与线上逐个一致、5 种迁移场景、错题间隔、16 种配题组合、识别与分组。
- 浏览器 932×430（iPhone Pro Max 横屏）实测：校准 → 秒答 / 慢了 / 写错描一遍 / 不会 / 识别确认 → 长按结束 → 结算 → 错题复习 → 快进一天错题回炉 → 家长区 → 竖屏提示，全部走通；过程中发现并修好 5 个问题（见 `审查/2026-10-25-代码审查.md`）。
