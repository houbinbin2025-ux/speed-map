## 选定：方向 A · 像素方块岛

**一句话**：一座浮空小岛，岛上是一级一级的方块台阶，四级颜色就是熟练度四档（灰 → 淡黄 → 淡红 → 深红）。爬到最高的深红方块，就是练熟了。

**为什么推荐 A**
1. **品牌就是游戏机制**：台阶的四个颜色就是孩子每天在地图上点亮的四档颜色。看见 logo 就知道"往上爬 = 练熟"，不用解释。别家标杆都没有这层对应（见调研第一部分）。
2. **和空空喜欢的东西同一个味道**：方块、像素、浮空岛，和 Minecraft 同一个家族，也和现有页面的像素风、「世界」「Boss」一致。但没有照抄 Minecraft 的字体和石头纹理。
3. **0 依赖**：中英文字标都是逐格手绘的像素字（SVG 矩形），不需要装任何字体，换哪台电脑都长一样。
4. **小尺寸最稳**：本来就是 16×16 网格画的，16px favicon（浏览器标签页小图标）上每一格都对齐像素，不发虚。

**不选 A 的代价**：选 B，"板块"的故事讲得更直白，但字标要靠系统圆体，没有自己的字；选 C，最克制、最好印刷，但孩子不会觉得是游戏。

**A 的已知风险**（自审遗留）：台阶在大人眼里有一点像柱状图；11×11 像素的「数」偏挤。定稿轮可以改成 12×12 网格再画一遍。

## 3. 字体（不加任何外部依赖）

| 用途 | 字体 | 说明 |
|---|---|---|
| logo 字标（中英） | 无，手绘像素 SVG | 只用 SVG 文件，**不要用别的字体重新打一遍「空空数学岛」** |
| 页面中文 | `--f-cn`：PingFang SC / Hiragino Sans GB / 微软雅黑 / 系统字体 | 沿用现有 |
| 数字、算式 | `--f-num`：ui-rounded / SF Pro Rounded / Arial Rounded MT Bold | 沿用现有，等宽数字 `tabular-nums` |
| 像素小标题（英文） | 现在：`--f-px` 等宽字体代替；以后可以把 `gen.py` 里的 5×7 英文像素字做成几 KB 的本地小字体 | 不引 CDN 字体 |

## 4. 图标与 favicon 规格

| 场景 | 文件 | 接入写法（等 Ben 选定后，由接入会话做） |
|---|---|---|
| 浏览器标签页 | `favicon-16.svg` + `favicon-32.svg` | `<link rel="icon" href="…/favicon-32.svg" type="image/svg+xml">`；另导出 `favicon.ico` 兜底 |
| iPhone Safari「添加到主屏幕」 | `app-icon-180.svg` 导出成 180×180 PNG | `<link rel="apple-touch-icon" href="…/app-icon-180.png">`（iOS 不认 SVG，必须是 PNG） |
| 页面顶栏 | `lockup-dark.svg`，高 40–56px | 替换 v1 的「SPEED MAP」绿标签 |
| 打印地图页眉 | `lockup-light.svg`，高 ≥ 12mm | 黑白打印时用 light 版，描边能保住形状 |

iOS 会自动把 180 图标裁成圆角，所以图标里不要自己画圆角。四周留 1 格（约 11px）安全边。

## 5. 留白和最小尺寸

- **留白**：组合版四周至少留**图形标宽度的 1/4**（= 4 格），这个范围内不放其他文字和图形。
- **最小尺寸**：
  - 组合版 ≥ 高 40px（屏幕）/ 12mm（打印）；再小就只用图形标（第 3 轮实测：32px 高时中文笔画只剩约 1.4px，太细）；
  - 图形标 ≥ 16px，16px 一定用 `favicon-16.svg`，不要用 `mark.svg` 缩小；
  - 英文字标单独用时 ≥ 高 14px。
- 缩放时按**整数倍**最好（16 → 32 → 48 …），像素格不会糊。

## 6. 错误用法 4 条

1. **不要拉伸、压扁、斜切**：像素格必须保持正方形。
2. **不要加渐变、阴影、发光、描边特效**：品牌的立体感只来自"每块方块压暗一格"，额外特效 = AI 味。
3. **不要换颜色顺序或换颜色**：台阶从低到高永远是灰 → 淡黄 → 淡红 → 深红。换了，就和游戏里的熟练度对不上。
4. **不要放在对比不足的底上**：比如草绿底、淡红底、照片上。只放在 `--cave` 深底或 `--paper` 浅底上，其他底就加一块深底色块托住。

## 7. 以后加板块怎么延伸

岛上每多一个板块（口算秒答 → 下一个板块……），就在岛上多一组台阶，或者用同一个台阶符号配板块名。**不要给每个板块另做一个 logo**。板块图标沿用 16 格像素网格、黑描边、四档色，保持是一家人。
