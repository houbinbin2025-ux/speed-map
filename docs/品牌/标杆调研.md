# KongMath · 空空数学岛 · 标杆调研

> 2026-10-27 · 品牌设计会话。结论先行，细节在后。
> 标签：✅ 已查到来源 · 🔍 基于公开可见的产品形象做的推论（没逐一核对官方规范）

## 结论（先看这 5 条）

1. **好的儿童学习品牌都只靠一个"记忆形状"撑住小尺寸**：Duolingo 是猫头鹰的圆脸轮廓，Minecraft 图标是一块草方块，Numberblocks 是"带脸的方块"。没有一个靠字标撑 16px。→ 我们的图形标必须在 16px 下只剩一个形状还能认出来。
2. **字标要从图形里长出来，不要另外套一个字体**：Duolingo 2019 年改版就是从猫头鹰的羽毛形状里画出字母（✅ Johnson Banks + Fontsmith，定制字体 Feather Bold）。→ 我们的字标笔画应该和图形标用同一套网格（像素方块）。
3. **Minecraft 的识别靠"材质 + 方块"，不靠像素字体本身**：主 logo 是石头质感的块状字，游戏内文字才用像素字体（✅ Mojang 2021 拆成扁平版的系列标和保留石纹的游戏标）。→ 不要照抄像素字体 + 石纹（那是 Mojang 的财产，也俗）；借的是"方块是基本单位"这条逻辑。
4. **Numberblocks 证明"数 = 方块"对 6–8 岁孩子天然成立**：数字 3 就是 3 块方块叠起来（✅ BBC / Blue Zoo）。→ 我们的岛可以直接由方块搭成，"一级一级升级 = 一层一层加方块"，故事不用额外解释。
5. **AI 味的来源是"通用吉祥物 + 渐变 + 光效"**，而不是"用了 AI"。业界做法是让 AI 写矢量 SVG、走结构化流程、人在关键点拍板，而不是一键出图（见第二部分）。

## 第一部分 · 竞品标杆拆解

| # | 标杆 | 形状 | 字标 | 配色 | 小尺寸能不能认出 | 我们能借的 |
|---|---|---|---|---|---|---|
| 1 | **Duolingo** | 猫头鹰 Duo，圆脸 + 两只大眼（✅ 2019 年改版画得更圆、更有表情） | Feather Bold，从羽毛形状画出的圆头粗体，g 有小勾（✅） | 一个主绿统治一切 | 能。图标只剩眼睛 + 轮廓 | 一个颜色 + 一个形状打天下；字标从图形里长出来 |
| 2 | **Minecraft** | 草方块（顶面绿、侧面土色） 🔍 | 块状石头字；2021 起分成扁平系列标和石纹游戏标（✅） | 草绿 + 泥土棕 + 石灰 | 能。草方块 16px 也认得 | "方块是最小单位"；顶面草绿 / 侧面土色这种两色块面法 |
| 3 | **Numberblocks** | 带脸的方块，数字 N = N 块（✅ BBC / Blue Zoo） | 每个字母一个颜色（🔍 来源可信度低） | 每个数字一个固定色 | 方块能，彩色字标不能 | 数 = 方块的直观对应；但"每字一色"太吵，不学 |
| 4 | **Khan Academy Kids** | 小熊 Kodi 当向导（✅ 官方页） | 圆体无衬线 🔍 | 柔和色系 🔍 | 图标靠角色头像 | 反面教材：通用可爱动物是"吉祥物套路"，容易撞 AI 味 |
| 5 | **Endless Numbers**（Originator） | 数字本身就是角色 🔍 | 粗圆体，字母间有小怪物 🔍 | 高饱和多色 🔍 | 图标是单个大数字 | 用一个大数字做图标在小尺寸上很稳 |
| 6 | **DragonBox** | 小龙 + 箱子 🔍 | 粗体无衬线 🔍 | 冷暖对比 🔍 | 图标靠单个角色 | "把数学藏进游戏"的定位，和我们一致 |
| 7 | **Monument Valley**（ustwo） | 等距（斜 45° 立体）几何建筑 🔍 | 细衬线，克制 🔍 | 低饱和粉、青、米 🔍 | 图标是单栋等距塔 | 等距视角让"岛"看起来像一个可以走进去的世界；克制配色不俗 |
| 8 | **Toca Boca** | 无角色，纯字标 + 色块 🔍 | 粗字标，略歪斜 🔍 | 每款 app 一个色 🔍 | 图标是色块 + 字 | 字标优先的可能性：一个强字标 + 一种颜色也能做儿童品牌 |

### 对 KongMath 的三条推导

- **岛 = 方块搭的**：借 Minecraft 的方块单位和 Numberblocks 的"数 = 方块"，空空一眼就懂，而且和现有页面的像素风、「世界」「Boss」完全一致。
- **颜色只用自家的**：沿用现有的草绿 `--grass` + 四档熟练度色（灰、淡黄、淡红、深红）。熟练度色本身就是"一级一级升级"，品牌色和游戏机制是同一套语言。这是别家没有的。
- **不要吉祥物**：Kodi 式可爱动物在 AI 时代最容易显得像套模板。用方块和数字本身做角色。

## 第二部分 · 业界现在怎么用 AI 做 logo（应 Ben 要求补充）

### 1. 主流做法：AI 写矢量代码，不一键出图

- 社区里给 Claude Code 做的 logo 技能（skill）基本都是同一套流程：**先问品牌 → 出 3 个 SVG 方向 → 人选 → 精修 → 导出多尺寸**。例子：
  - `neonwatty/logo-designer-skill`：4 阶段：访谈 → 多个 SVG 概念 → 精修 → 导出 16px–2048px PNG（✅ [GitHub](https://github.com/neonwatty/logo-designer-skill)）
  - `logo-design-skill`：自带 1400+ 个参考 SVG logo，审查脚本会检查复杂度、角度、对比度和 **16px 可读性**，三个方向出来后停下等人审（✅ [SourceForge 镜像](https://sourceforge.net/projects/logo-design-skill.mirror/)、[AlphaSignal](https://alphasignal.ai/news/open-source-skill-gives-claude-a-structured-logo-design-workflow)）
  - `op7418/logo-generator`：先问几个问题，再出 SVG 和展示图（✅ [Claude Marketplaces](https://claudemarketplaces.com/skills/op7418/logo-generator-skill/logo-generator)）
- Claude 本身画 logo 走的是 SVG 代码，所以任意尺寸都清晰（✅ [Analytics Vidhya 2026-06](https://www.analyticsvidhya.com/blog/2026/06/claude-image-generation/)）。

### 2. 专业设计师的多工具分工（主要是文生图路线）

- 常见管线：Midjourney 等先出位图概念 → Ideogram 处理字标 → **Recraft 出原生矢量 SVG 定稿** 或 Adobe Firefly 文字转矢量（✅ [rangy.ai](https://rangy.ai/blog/best-ai-logo-generator-2026)、[MindStudio](https://www.mindstudio.ai/blog/recraft-v4-1-brand-design-logos-svg-assets)；多为厂商或联盟博客，版本说法互相矛盾）。
- 提示词约束通常是：纯色块、正面、不要渐变、不要阴影、不要高光，**32px 下要能读**（✅ [Picsart](https://picsart.com/blog/use-recraft-v4-1-for-ai-logo-design/)）。
- 风险：Looka、Brandmark 这类一键套件出的标，**商标显著性有风险**，容易和别人撞。

### 3. MCP（给 AI 接外部工具的接口）

- **Figma MCP**：多个社区版，能读设计稿、导出选中图层为 SVG、回写颜色变量（✅ [Glama 列表](https://glama.ai/mcp/servers/rlagudals95/mcp_figma)）。适合"已经有 Figma 稿"的团队，我们没有。
- **Branding MCP**：号称能生成 logo、favicon（浏览器标签页小图标）、分享卡片图，并导出设计变量（✅ [G2 市场](https://ai.g2.com/marketplace/tools/branding-mcp)；功能和维护状态没核实）。
- **图标库 MCP**（Iconify、Icons8）：给的是现成图标，不是 logo。
- 没找到官方的 Recraft MCP。

### 4. 我们用哪套（建议）

| 选项 | 用不用 | 原因 |
|---|---|---|
| 本机已装的 `logo-design` 技能（4 阶段 + 定稿只用 SVG + 浏览器引擎导出） | **用（主流程）** | 流程和社区主流一致，而且是 Ben 的规则已经沉淀过的版本 |
| Claude Design 画布 | **用（展示 + Ben 拍板）** | 3 个方向并排放，Ben 能直接在画布上评论 |
| 借鉴 `logo-design-skill` 的 16px 自动审查思路 | **借思路，不装** | 装第三方技能 = 新依赖，需要 Ben 点头；16px 检查我在自审里用浏览器真截图来做 |
| Recraft / Midjourney / 任何文生图 | **不用** | Ben 明令禁止；而且中文字标在生图里必糊 |
| Figma MCP / Branding MCP | **不用** | 没有 Figma 稿；Branding MCP 是一键套件路线，正好是 Ben 嫌弃的那种 |

**关键流程点（"不闷头做"）**：三个方向的草案上画布后，**先停下给 Ben 选**，选定之后才做完整品牌体系和定稿导出。
