## 第 4 条 · 小数加减写完整得数（B 侧，和 A 的 9afb562 同版上线）
A 把 `speed:g12:dec`、`speed:g14:dec2` 改成写完整得数（ans 存去掉小数点的整数，`q.dp` = 小数位数），见 `docs/说明书-小数加减写完整得数.md`。B 做的：
| 地方 | 现在 |
|---|---|
| 答对的整道式子、口答「答案是」、家长区题库预览 | 按 `R.ansText` 带小数点（14.3，不是 143） |
| 答错「你写的是」、手机确认弹窗 | 孩子写的数按小数位数加回小数点（写字板不记点）；蓝框写错位置时照原样显示 |
| 描红 | 带小数点 |
| 手机写字板 | 孩子写「14.3」：小数点当误碰不算，认成 143 判对；漏写小数点也判对；不弹「一格只写一个数」（真写验证见下） |
| iPad 蓝框 | 答案格里印一个固定小数点（倒数第 dp 格前），孩子不写点；格数 = 这个题型最长答案 + 1；整数部分靠着小数点、小数部分写到最右格才对，写偏了提示「小数部分写在小数点后面的格子里」；正确写法带小数点；原来的 `2.□` 单格版面这两个题型不再用（旧错题照旧） |
| 秒答时间 | 一位小数想 8 秒（原 6），两位小数 12 秒（原 8）：现在整数部分也要算；写字时间按完整得数的位数 |

验证：`tools/e2e/e2e-dec.py` 44 项（手机 844×390 真写「14.3」「13.29」，带点和不带点各写，写错、描红、口答；iPad Safari 和 App 尺寸真写判对、答错正确写法带点）。

## 可能影响什么
- 只影响 iPad 竖式 / 蓝框题、数线题、笔迹存档、两种小数加减题（含它们的秒答时间）。其余题型、排课、奖励不变。
- 存档结构没改（只是多了一个坏值备份键，正常情况下不会出现）。
- 数线题的「不会」走和其他题一样的「不会」流程（进错题集、讲解、点「继续」）。
- 笔迹读报错时这次打开不存新笔迹：这次写的字不进识别样本，下次正常打开就恢复；家长导入笔迹或重新校准算主动覆盖，照常写入。
