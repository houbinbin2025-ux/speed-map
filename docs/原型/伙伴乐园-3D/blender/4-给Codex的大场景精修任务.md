## 背景
给 7 岁孩子做的「小伙伴乐园」网页：俯瞰的微缩小岛，中间是广场（小卖部 + 传送门），送粮传送带放射到各家；三户人家（小狼、熊猫、美西螈）各有小屋和食盆水槽，其余 5 块是待开放空地。目标画面质量 = 附图 1、2（别人做的微缩小镇：圆润玩具 / 粘土质感、倒角、层次多但不杂）。附图 3 是当前大场景预览。
**小狼一家（地块-小狼 下面的全部东西）已经精修过，一点都不要改。**

## 文件（都在当前目录）
- `build2.py`、`lib.py`：搭大场景的脚本（读它，了解每个部件的位置和命名）。
- `out/big/park2.blend`：大场景基础模型；`out/big/layout.json`：网页用的布局数据（不要改）。
- `refine.py`：你上次精修小狼一家时写的脚本，可参考做法。
- Blender：`/Applications/Blender.app/Contents/MacOS/Blender`（5.x）。运行：`/Applications/Blender.app/Contents/MacOS/Blender -b out/big/park2.blend --python refine2.py -- out/big-refined`

## 要做
写 `refine2.py`：打开 park2.blend，在原模型上改，产出 `out/big-refined/park2.blend`、`out/big-refined/park2.glb`（GLB，`export_apply=True`，Y 向上）、三张预览：`preview-wide.png`（整体俯视，和 build2.py 的预览相机一致）、`preview-panda.png`（熊猫一家特写）、`preview-axo.png`（美西螈一家特写）。预览用 Eevee + AgX，只用来自查，导出前删掉预览用的相机、灯、地面。
重点（按这个顺序）：
1. **熊猫**和**美西螈**：做到和小狼同一水平（参考 refine.py 对小狼做的：眉毛、脸颊毛团、双高光眼睛、肉垫趾缝、更圆的轮廓）。熊猫要有黑眼圈、黑耳朵、黑四肢的辨识度；美西螈要有粉色身体、两侧三根羽状鳃、长尾巴。
2. **竹林小亭**、**荷叶池塘**：做到和红顶木屋同一水平（瓦片错缝、屋檐厚度、柱础、竹节、荷叶有起伏、圆顶屋砖缝和门窗细节）。
3. **小卖部**（遮阳棚、粮袋、水桶、招牌）和**传送门**（石框、发光面）：精致化；**传送带**：做出滚筒或分节、两侧护栏、支柱，像附图 1 里的传送带。
4. 空地的「待开放」牌子精致一点即可。
材质：Principled BSDF，粗糙度 0.45–0.85，金属只用于小件；只用 Base Color / Roughness / Metallic / Emission，**不要贴图、程序纹理、节点组**。
