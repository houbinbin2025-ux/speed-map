你是 3D 建模师，用 Blender 的 Python 脚本（无界面模式）精修一套已经搭好的模型。中文汇报。

## 背景
给 7 岁孩子做的「小伙伴乐园」网页：一座俯瞰的微缩小岛，孩子给自己的小伙伴喂粮喂水。目标画面质量 = 附图 1（别人做的微缩小镇实时网页截图）：圆润的玩具 / 粘土质感、每样东西都有倒角和层次、细节多但不杂、配色清新。附图 2 是现在这套模型的预览（主视觉已经定了）。你的任务是在这个模型上「雕刻优化」，把精度和质感提到附图 1 的水平，**不要推翻造型和配色方向**。

## 文件（都在当前目录）
- `build.py`：搭基础模型的脚本（读它，了解每个部件的位置和命名）。
- `out/base/park.blend`：基础模型。`out/base/preview.png`：预览。
- Blender：`/Applications/Blender.app/Contents/MacOS/Blender`（5.x）。运行：`/Applications/Blender.app/Contents/MacOS/Blender -b out/base/park.blend --python refine.py -- out/refined`

## 要做
写 `refine.py`：打开 park.blend，在原模型上改，产出 `out/refined/park.blend`、`out/refined/park.glb`（GLB，`export_apply=True`，Y 向上）、两张预览 `out/refined/preview-front.png`（正面 3/4 俯视）和 `out/refined/preview-close.png`（小狼特写）。预览用 Eevee、AgX、柔和太阳光加天空光，只用来自查，**不要导出进 GLB**（导出前删掉预览用的相机、灯、地面）。
重点：
1. **小狼**：更可爱、更像玩具。头身比再大一点；轮廓更柔（加大倒角或加细分）；脸上加层次（如脸颊毛簇、眼睛高光更明显、眉毛小色块），爪子加肉垫或趾缝；围巾做出布料感（打结、垂角）。
2. **红顶木屋**：原木墙在四角露出圆圆的木头截面（交错搭接）；屋顶瓦片有起伏和错缝，屋檐有厚度；门窗加细节（门上小窗或铰链、窗边百叶）；墙脚石做成不规则的石块；烟囱砖块分块。
3. **地块小物**：食盆、水槽、灯笼、栅栏、灌木更精致（圆边、木纹分块、灌木更蓬）。可以加 2–4 个小装饰（蘑菇、小木箱、信箱、花丛），放在不挡路和不挡小狼的地方。
4. 材质：Principled BSDF，粗糙度 0.45–0.85，金属只用在门把这类小件；颜色只用 Base Color（网页端只读 Base Color / Roughness / Metallic / Emission，**不要用贴图、程序纹理或节点组**，导出后会丢）。
