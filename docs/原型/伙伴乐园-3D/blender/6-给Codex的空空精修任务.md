你是 3D 建模师，用 Blender 的 Python 脚本（无界面模式）精修一个已经搭好的玩家角色。中文汇报。

## 背景
给 7 岁孩子做的「小伙伴乐园」网页，玩家角色叫「空空」（原创角色，来自孩子自己的方块世界游戏）：大头、棕色头发 + 头顶一根呆毛、绿上衣、蓝裤子、红围巾、棕色背包、背包侧挂小灯。他要和你上次精修的小狼、熊猫、美西螈站在一起，**质量要同一水平**（圆润玩具 / 粘土质感、倒角、层次多但不杂）。附图 1、2 是参考质量，附图 3 是当前基础造型预览。保持方块感的 Q 版比例（大头小身，头约占身高 40%），不要做成写实人类。

## 文件（都在当前目录）
- `build3_kong.py`、`lib.py`：搭基础造型的脚本（读它，了解部件和命名）。
- `out/kong/kong.blend`：基础模型。
- `refine.py`：你上次精修小狼的脚本，可参考做法。
- Blender：`/Applications/Blender.app/Contents/MacOS/Blender`。运行：`/Applications/Blender.app/Contents/MacOS/Blender -b out/kong/kong.blend --python refine3.py -- out/kong-refined`

## 要做
写 `refine3.py`：打开 kong.blend，在原模型上改，产出 `out/kong-refined/kong.blend`、`out/kong-refined/kong.glb`（GLB，`export_apply=True`，Y 向上）、两张预览 `preview-front.png`（正面偏左 3/4）、`preview-back.png`（背面 3/4，看背包和小灯）。预览用 Eevee + AgX，只用来自查，导出前删掉预览用的相机、灯、地面。
重点：
1. 脸：可爱有神（双高光眼睛、小眉毛、脸颊红晕、小嘴），头发要有发块层次和发梢，不要像头盔；鬓角贴脸，不要外翻；呆毛一根弯曲有弧度。
2. 衣服：上衣领口 / 袖口 / 下摆有厚度和包边，围巾有打结和两条垂角、针织感用分段表现；裤子有裤脚卷边；鞋有鞋底和鞋带块。
3. 背包：有翻盖、搭扣、两条肩带从肩上绕到前面；小灯有玻璃罩和金属框（灯芯材质名保持 `灯芯`，玻璃材质名 `玻璃`）。
4. 手：袖口下露出圆润的手（可以是连指手套式的方块手），不要只是长方块。
材质：Principled BSDF，粗糙度 0.45–0.85，金属只用于小件；只用 Base Color / Roughness / Metallic / Emission，**不要贴图、程序纹理、节点组**。

## 硬约束（违反就返工）
- 名字和原点位置不能改：`空空`、`空空/头`、`空空/左臂`、`空空/右臂`、`空空/左腿`、`空空/右腿`（这些是网页做走路、挥手动画的支点：头在脖子、臂在肩、腿在髋）。新加的部件挂到对应父物体下（脸、头发挂 `/头`，手和袖口挂对应 `/臂`，鞋和裤脚挂对应 `/腿`，围巾背包挂 `空空`）。
- 不要改变整体高度（脚底 z=0，头顶约 2.0，不含呆毛）和朝向（脸朝 -Y）。
- 三角形数 ≤ 40,000（导出后统计并打印）。
- 全部原创，不下载素材、不联网、不装插件；只在当前目录读写。
