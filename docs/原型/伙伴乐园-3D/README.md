# 伙伴乐园 · 3D 样例

照卡兹克帖子（x.com/Khazix0918/status/2114343004471460341）作者自己说的做法做的样例：Claude 搭主视觉，GPT/Codex 操控 Blender 精修模型，网页实时渲染。**没有改方块世界和数学岛的任何代码。**

- 第 1 版（`web/`）：一只小狼、一间红顶木屋和门前喂养，定画面质量和做法。
- 第 2 版（`web2/`，在线链接现在是这一版）：照原帖的大场景和动作。中心广场（小卖部 + 传送门），送粮传送带放射到三户人家（小狼 / 熊猫 / 美西螈），5 块待开放空地；开场镜头俯冲、名牌依次弹出、待机镜头漂移、伙伴溜达；倒粮倒水 = 爆炸框 → 粮箱上传送带 → 镜头跟拍 → 跳进食盆 → 伙伴蹦一下冒爱心；「看一天」= 12 秒延时昼夜。

在线看（私有链接）：https://claude.ai/artifact/RSwvA4Di9YMHmtMPHoEhqz

## 实施时必须知道的坑（都踩过）
1. 天空不要用贴图背景（`scene.background = 贴图`）：开了环境光遮蔽后，会在原点画出一块黑片。用天空球。
2. 只把材质设为不可见的点击盒，也会被环境光遮蔽画出来：点击盒本身要 `visible = false`（射线点击不受影响）。
3. 精灵贴片（爱心等）进主场景会被画成黑块：放进单独一层，在后期处理之后再叠上去。
4. Blender 里给空物体（旋转支点）挂父物体时要换算坐标，否则支点位置会被叠加两次，动作会绕错的点转。
5. Artifact 不收 `.glb`：用 glTF 文本，二进制用 base64 内嵌。
6. Artifact 的安全策略拦同目录上传的 `.js`（页面外壳会显示，但脚本一行不跑）：发布版 `web/artifact.html` 把 `main.js` 内联，three.js 改从 jsDelivr 锁版本 0.170.0 加载。正式做进方块世界时仍用本地文件，不走 CDN。
8. GLTFLoader 会删掉节点名里的 `/`（`熊猫/头` 读进来是 `熊猫头`），网页按删掉后的名字找。
9. 3000 多个零件逐个画会掉到 34 帧：加载后把不会动的零件按材质合并（`mergeStatic()`），树也按颜色合并，每帧绘制从约 1.9 万次降到 2–3 千次，回到 60 帧。
7. Artifact 也拦加载器去读 `data:` 地址：`main.js` 的 `loadPark()` 自己用相对路径读 `park.json`、解码、拼回 GLB 再解析。

## 第 3 版（2026-11-09）：我的世界玩法 + 空空本人 + 和伙伴互动（`web3/`）
Ben 11-09：「整个动作为啥不是原来我的世界的模式？需要增加和小动物互动的功能。空空的形象呢？」
- **空空**：照方块世界 V4 的原创空空（大头、棕发呆毛、绿衣蓝裤、红围巾、背包小灯），Claude 搭基础造型（`blender/5-空空基础造型-build3.py`）→ Codex 操控 Blender 精修三轮（`blender/6-空空精修-refine3.py`，3.2 万三角形，头 / 两臂 / 两腿支点不变）。前后对比：`截图-空空精修前后.png`。
- **走走模式（默认）**：和方块世界同一套操作——WASD 或摇杆走、空格跳、拖动转向、V 切第一人称 / 背后 / 正面、1–4 或滚轮换快捷栏、E（或点伙伴、右键）互动、M 切俯瞰。有碰撞：房子、栅栏、树、池塘、岛边挡路，矮的东西能跳上去站。俯瞰模式保留第 2 版的传送带送粮和看一天。
- **互动（对齐 V5 设计）**：小卖部花 1 宝石装满粮袋 / 水桶（最多 3 份）→ 走到食盆、水槽前倒 → 伙伴跑过来吃，吃完蹦一下冒爱心；摸摸加亲密度；伙伴见到空空会转头看、摇尾巴，蔫蔫的会抬头；亲密度 1 颗心跟着走，2 颗心接球（扔出去叼回来），3 颗心送装饰（只有提示，装饰没做）。
- 截图：`截图-走走模式互动.png`。
- 坑：`web3/park2.glb`、`vendor` 是指向 `web2/` 的链接，别重复存 10MB；打包 Artifact 要带两个模型：`python3 打包成Artifact.py web3 <输出目录> park2.glb,kong.glb layout.json`。第三人称镜头碰撞要沿线密采样（22 点），稀了会穿墙进屋。
