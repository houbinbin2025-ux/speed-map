## 改了什么（白话）
- 每道错题现在记：错了几次（`wrongs`）、最近 5 次经过（哪天、写错 / 不会 / 对但慢、孩子写了什么、几秒、是不是口答），按技能累计，每天新增 / 过关几道。家长区以后能看「这道题空空写的是 22」。
- 孩子写了什么（`w`）：
  | 题型 | 记什么 |
  |---|---|
  | 手机写字板 | 识别结果；小数题加回小数点（写 14.3 记「14.3」） |
  | iPad 竖式 / 蓝框 | 格子里写的数（中间空格记成 □） |
  | 选择题 | 点的选项文字 |
  | 数线 | 插旗的数（一位小数） |
  | 点「不会」、口答 | 不记（口答另记 `o:1`） |
- 什么时候记：新进错题本、在本里又错、复习时答对但慢；复习过最后一关记一次过关。秒答下架（`out`）不算过关。
- 不记：再来一次、看过提示、摸底、Boss（和能力观察同一口径）。
- 顺带两处（F 提的）：
  - 秒答下架（`sweep`）时写 `last`：两台设备互相导入时，已下架的题不会被带回复习。
  - 下架过的题又错了、重新进本时，清掉下架标记 `out`。

## 可能影响什么
- 只多记录，排课不变：用 `tools/compare-engine.js` 同种子跑 4 个种子 × 约 6870 题，去掉新记录字段和 `last` 后存档完全一样（差异 0）。
- 存档每道错题多几十字节；体积上限、导入合并、清洗都在 F 的函数里（`tests/mistake-data.test.js`）。
- `engine.js` 多导出一个 `settle`（给页面回归用），不影响别处。

## 怎么退回
- `git revert` 这次提交，跑 `node tools/bump-version.js`。已经记下的新字段留在存档里也无害（F 的清洗会保留，旧代码不读）。
