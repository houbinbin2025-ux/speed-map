# 说明书 · 习惯记录和能力观察（第一步，2026-11-06）

> 意图：`docs/意图-学习习惯.md`。档位：**可交付**（进正式 `/v2/` 和 iPad）。对标：可汗学院家长报告的「只看不改」。Ben 11-06 说「开始第一步」。

## 硬边界：只记录
**孩子看到的一切、排课、判题、升级、下架都不变。** 记录写在新增字段里，出错也不影响作答。

## 记什么
| 数据 | 存在哪 | 内容 |
|---|---|---|
| 每日作答 | `S.stats[日].h` | `a` 作答数、`r` 答对、`d` 点「不会」、`k` 熟题作答、`ks` 熟题失误、`wn` 文字题数、`ws` 文字题秒数 |
| 每日书写 | `S.stats[日].h` | `in` 写的数字个数、`is` 书写评分之和、`ia` 答案数、`ic` 笔迹清楚的答案数 |
| 朗读 | `S.stats[日].h.say` | 点朗读按钮的次数 |
| 最近失误 | `S.slips` | 最近 30 道熟题失误，显示用 |
| 最近写的字 | 笔迹存档 `INKS.recent` | 最近 24 个答案的简化笔画、每位的评分、日期 |

**统计口径**：
- **熟题**：作答前所在格已到淡红以上，或这道题已在不同的日子算过 2 次秒答。
- **失误**：熟题答错，不含点「不会」。
- 「当场再来一次」和看过提示的题不计，新旧摸底和 Boss 关也不计；书写记录和作答统计同一口径，在定案后才写。
- 已知局限：写对但被识别错，会算失误；可以对照「最近写的字」。
- 文字题 = 题目带 `say`。

旧存档没有这些字段时按 0 算。每日记录约 53 字节，一年约 20 KB；`S.stats` 目前没有裁剪（`trimStats` 没人调用），这是原有情况。导入合并时，习惯记录按天取大，最近失误合并去重。清空进度时一起清最近写的字；重新校准保留。

## 书写评分（试运行）
和一套内置的规范字形比（`I.legibility`），0–100，不和孩子自己的模板比。

**没用真实笔迹校准过**，所以页面标明「试运行」，也不设「工整 / 潦草」的门槛。2 周后由 Ben 对照「最近写的字」判断评分和肉眼是否一致。

## 能力观察页
家长区加一块「能力观察」，点开是单独一页（近 14 天，和前 14 天比）：
- 有作答的天数和作答数、正确率、「不会」占比；
- 熟题失误率；
- 书写评分（不做前后对比，不同数字不可比）、免确认识别率（是识别的把握，不代表工整）；
- 文字题平均用时、朗读次数；
- 最近写的字（真实笔画 + 评分）、最近失误的题。
