# 说明书 · 挑战题（家长勾选的更高难度）

> Ben 11-04：「所有板块的题目，只有幼龄的，应该再加一个更高难度的，可以后台勾选设置。需要的时候使用。」

## 做什么
家长区「挑战题」：6 个板块各一个勾选框，默认全关。勾上后，这个板块的挑战题排在今天要学的新题最前面，也出现在「练这一块」里。取消勾选就不再出，进度留着，再勾上接着练。

| 板块 | 挑战题 | 大致对应 |
|---|---|---|
| 看数 | 几排几个（点阵）、百格图数数 | 乘法启蒙、100 以内数感 |
| 分合 | 整十分合（60 = 20 + □）、凑一百（37 + □ = 100） | 一下～二上 |
| 数位 | 看百十个写数、几个百几个十几个一 | 二下 |
| 比大小 | 三位数谁大、算式谁大（8 + 7 和 9 + 5） | 二下、一下 |
| 数线 | 0—1000 整百、0—1000 任意 | 二下 |
| 秒答 | 连加连减、两位数加减两位数、乘法（2、5、10） | 一下～二上 |

## 规则
- 新题放在独立题库 `v2/hardbank.js`（`tools/build-hard.js` 生成）、独立列表 `K.HARD`。`K.SKILLS` 不变：现有 38 个技能的格子、地图、奖状、伙伴全不受影响；挑战题不计入奖励（🔍 看空空用得怎样再决定要不要配奖状）。
- 家长勾选 = 明确要练，不等前面的技能学完（同一板块内部仍先易后难）。
- 升级规则同题型：最近 8 次合格 ≥ 7。比大小、分合、秒答的挑战题淡黄以后要快；看数、数位、数线不计时。挑战题的看数不闪现，让孩子能数。
- 写错照样进错题宝箱、当场再来一次。取消勾选后，这个板块挑战题的错题暂停复习，不占每日时间，再勾上继续。

## 数据
`S.settings.hard = {look: true, ...}`；进度存在 `S.skills`，错题在 `S.mistakes`，`src` = 所在板块（秒答挑战题 = `speedH`）。旧存档没有这个字段 = 全关，行为不变。回滚：旧代码不认识这些编号，错题页已按 `K.ITEM` 过滤，不崩。
