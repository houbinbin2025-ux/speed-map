# 时间分析 · 数据节律（2026-11-09）

| 数据 | 更新时机 | 晚了 / 缺了怎么显示 | 依赖它的功能 |
|---|---|---|---|
| 各活动时长 `S.time[日].a` | 在数学岛里实时累计：切屏、切后台、每次点按时结算；存档随每次保存写入 | 上线前的日子显示「上线前未记录」；只有部分记录的日子显示「数据不全」，不显示 0 | 时间去向、每日时长、奖励占比 |
| 投入 / 答对 / 秒答秒数 `e / ok / fast` | 每次交卷，用 `readSecs`（不含答后停留） | 同上 | 有效学习占比 |
| 无操作 `idle` | 出题页超过单题上限、讲解卡超过 90 秒、其他页超过 60 秒没点按后开始累计 | 同上 | 无操作占比 |
| 分时段 `hr` | 每次交卷 | 不满 14 天显示「数据不足」，不画结论 | 分时段效率 |
| 练习前后半段 `seg` | 每段练习结束（结算页）时写入一条；练到一半退出的按已答的题算 | 少于 6 题的段不判 | 后半段表现 |
| 方块世界、伙伴乐园 `a.w / a.k` | **不是实时**：方块世界在另一个页面，数学岛下次打开时从 `mc_unlock.log` 读进来 | 显示「方块世界数据截至上次打开数学岛」；手机网页没有方块世界，不显示这一项 | 时间去向、奖励占比 |
| 已有的每日统计 `S.stats` | 每次交卷（原样） | 原样 | 作答、正确率、秒答率（旧日子也能算） |

- 页面上的「今天」是到最后一次保存为止的数据，不写「实时」。
- 手机和 iPad 各记各的；互发进度后按天、按项取大。两台设备同一天都用时会少算，页面口径说明里写明。
