# 意图卡 · 写字认真、会的题少犯错（门 0，2026-11-06）

## Ben 的原话
「目前一年级，其他的在练习中查看他的能力吧，每周大概 5 天。在家上课，不在乎什么教程，可信是底层的学习能力和学习习惯。比如写字要认真（这个要求可以慢慢趋严），然后做题，特别会的题少犯错。」

（「可信是」按「看重的是」理解。）

## 我理解的诉求
1. **底层能力和习惯比教材进度重要**。题库不用跟任何教材同步，按前置关系和孩子的表现走。
2. **写字要认真，要求逐步变严**：一开始不卡，慢慢提高。
3. **会的题要稳**：已经会的题不该因为不认真丢分。
4. **能力从练习数据里看**：不靠家长填，也不靠年级推。

## 优先级（新）
**对 > 工整 > 快。** 现在的奖励只认「对 + 快」，这次要把后两者的关系理顺。

## 方案

### 一、写字认真：分四档，自动慢慢变严

**怎么算工整**：不和孩子自己的模板比，另存一套**标杆字**（校准时选空空写得最好的，或内置规范字形），比和标杆的距离、大小、有没有出格，再和空空自己过去的水平比。`$P` 匹配不看笔顺，所以这一期不评笔顺。

**先改两处**：
- 只有写得够工整的笔迹才进识别模板，防止越写越乱。
- 工整度只用来评字，答案仍要认得准。到第 2 档起，熟题不再用答案定夺。

| 档 | 孩子遇到什么 | 进入条件（数字待校准） |
|---|---|---|
| 0 只记录 | 没有变化。家长区能看到**最近写的字**和趋势 | 上线就是 |
| 1 提示 | 写得好时显示「书写工整」，不好不批评 | 看过记录，Ben 认可评分和肉眼一致 |
| 2 重写 | 明显潦草的，要求重写一次，不计错 | 上一档工整率连续 2 周 ≥ 80% |
| 3 算数 | 字不工整，这题答对但不算秒答，不计下架和升级 | 上一档工整率连续 2 周 ≥ 90% |

- 只升档不自动降档；放弃率或重写率明显变高时，家长区提示，由 Ben 决定退一档。
- 时限按工整时的写字速度算，避免为了快写乱。
- **门槛没法现在定**：评分准不准要用空空的真实笔迹验证，手指和触控笔差别也可能很大。所以第 0 档先上，至少攒 2 周。

### 二、会的题少犯错

**定义「熟题」**：所在格已到淡红以上，或这道题已秒答 2 次以上。

| 做法 | 内容 |
|---|---|
| 分错型 | 熟题答错记为「失误」，单独统计。家长区显示熟题失误率和常错的题；不给孩子贴「粗心」标签 |
| 先自查 | 熟题第一次写错，不直接给答案，提示「再看一遍」。改对了不算秒答，也计一次失误；再错才看讲解 |
| 下架计数回退 | 熟题失误后这道题的秒答次数减 1（不低于 0），所以要多证明一次才下架。Ben 的「4 次下架」不变 |
| 逐步收紧升级 | 失误率稳定后，淡红升深红从「8 次对 7 次」收紧到「8 次全对」；只影响新的升级，已有颜色不动 |
| 开新级要稳 | 自动开放下一级，除了 70% 格子淡黄，再加「本级最近 50 题正确率 ≥ 90%」，以后再提到 95% |
| 连对记录 | 结算页显示「会的题连对 N 题」和自己的最好成绩。不加新奖励，也不和别人比 |

**不做**：下架的题定期抽查。这和 Ben 11-05「累计秒答 4 次的题不再出」冲突；稳定性用同题型里未下架的题和下一级的题来看。

### 三、能力从练习里看

家长区加一页「能力观察」，都从现有作答算：读题（朗读按钮使用率、文字题用时）、计算（各级正确率和用时）、稳定（熟题失误率）、书写（工整率）、坚持（放弃率、每次完成度）。自动模式下，孩子能力决定开放到哪一级，年级不参与。

## 依据
**证据弱。** 查到的多是教学经验文章，❌ 没查到小学阶段「数字工整度和计算错误率」或「自查习惯和粗心错误」的对照研究（一次搜索，[PaTTAN 书写页](https://sites.google.com/pattan.net/ptnmath/handwriting)提到数字写不熟会拖慢书面计算；[Mathnasium](https://www.mathnasium.com/math-centers/midlothian/news/clerical-errors-math-accuracy) 主张检查习惯可以教）。所以用空空自己的数据判断有没有效：熟题失误率和工整率有没有降、放弃率有没有升。

## 不变的底线
- 进度不丢：只加记录字段，旧存档缺字段等于第 0 档。已有颜色不降。
- 孩子不被连续否定：第 0、1 档只记录和正面提示；同一题最多要求重写一次。
- 0 依赖、离线。

## 接入顺序
1. **马上可做，零风险**：第 0 档记录、熟题失误统计、能力观察页。
2. **看 2 周数据后**：模板只收工整笔迹、自查、计数回退、开级条件。
3. **再之后**：写字第 1–3 档、收紧升级。

这些改动和 15 级改动同样会动 `v2/engine.js`、`v2/index.html`，要等那边合并后再做；按流程先写说明书，再审查、真机试。
