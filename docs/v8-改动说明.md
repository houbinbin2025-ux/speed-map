# 思维模块改动说明（给 Ben 看的白话版，2026-11-06）

> 只改了 `/v2/`，根目录正式版 v1 没动。

## 改了什么
1. **岛变长了，过了故事码头的水面多了 4 个地方**：天平桥（等号两边相等）、凑数矿（加减凑目标数）、线索营地（迷你数独、找小狗）、方块工坊（对称、转一转）。
2. **点地方 → 练这一块**，和其他地方一样。卡片上显示「学会 x / 4 个技能」，木牌上学会一个技能亮一格。
3. **一步步开放**：每个技能做对 3 题，开放下一个。没开放的点不了。
4. **矿石照常累计**：一题一块，进总数。
5. **底部快捷栏**地点多了，手机上保持两行，放不下的横向滑。

## 不变的
- 每日练习的 10 分钟和排课完全不变，思维题是自己想玩才去。
- 不计时，不进四档颜色，不进错题宝箱。
- 其他 10 个地方、家、错题、秒答地图都不变。

## 可能影响什么
- 矿石总数会涨得快一点。家里的奖励条件不看矿石，不受影响（已实测）。
- 存档多一个 `think` 字段，旧进度不动；退回旧版也不受影响。
- 旧的原型地址现在会自动跳到 `/v2/`。

## 怎么退回
`git revert` 这次提交再推送。存档里多出的 `think` 字段不影响旧版本，不用清。
