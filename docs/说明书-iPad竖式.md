> Ben 11-07：「搭建并上线吧」。原型 `docs/原型/ipad/` Ben 试过两轮、审过示范卡；本说明书把其中 **竖式、乘法、除法竖式** 三种版面接进 v2 正式练习。应用题、递等式、填空等第二批 2b 和 iPad 原型对齐后再接。

## 一、范围
| 项 | 定 |
|---|---|
| 设备 | 横屏宽屏（窗口短边 ≥ 700 点，即 iPad；iPhone 不变），非口答模式 |
| 题型 | 7 个纯计算：`speed:g10:add3`、`speed:g10:sub3`（加减竖式）· `speed:g11:mul`、`speed:g12:mul2`、`speed:g13:mul3`（乘法竖式）· `speed:g11:div`、`speed:g13:div2`（除法竖式，都除得尽）|
| 其他三四年级手写题（Ben 11-08「做完上线」）| 38 个（`v2/vert.js` 的 `BOARD`）：递等式（`speed:g13:order`、`speed:g14:law`）· 填空（算式里有 □）· 应用题（故事题）|
| 其他题 | 照旧：左题右写字板 |

## 二、页面（同原型）
- 整屏宽版：上面题型标签，中间竖式卡片（按窗口等比缩放），右边一列 看示范 / 写好了 / 擦一笔 / 不会。
- 加减：进位退位小格一排 → 两个数 → 横线 → 答案格（加法比较长的数多一格）。
- 乘法：两个数 → 横线 → 进位条；乘两位数再加 草稿 / 进位 / 草稿（带横线）；答案格 = 两个因数位数之和。
- 除法：商格（被除数几位就几格）→ 厂字形 → 对齐数位的草稿区。
- 答案一格一位，每格单独识别；草稿、进位不识别、不判。点「写好了」才判（多位答案写到一半会停下来想，不能自动交）。

### 递等式 / 填空 / 应用题版面
- 题面照原样放在上方（应用题有喇叭，字放大），中间格子纸草稿，下面「答案」蓝框；递等式在格子纸上面多两行「=」。
- 答案格数：方框夹在数字中间（`2.□`、`11.□8`）一格；否则按这个题型最长的答案多一格（同一题型格数固定，不泄露这一道的位数）。
- 四则混合第一次先看示范（56 + 4 × 6，一行一步，每步说「先算 4 × 6 = 24」）；答错的正确写法按运算顺序一行一步（最里层括号先算，同一层先把每段乘除算完再算加减）。
- 运算律题要教的是简便算法：不放示范、不出按顺序硬算的正确写法，讲解里的简便算法就是正确写法。
- 填空答错的正确写法是把方框填上（没有方框的算式在等号后写上得数）的整个算式；应用题不另出正确写法框（讲解里有算式）。这两种没有示范、没有「一步一步看」。

## 三、判
- 答案格去掉前面空格后拼成数；中间空格、一格两个数 → 错（提示「一格只写一个数」）；最高位写 0 → 错（提示「最高位不写 0」）；个位没写在最右格 → 错（提示「个位写在最右边的格子里」）。
- 某一格认不出：清掉那一格、提示重写，不算错。很小的点和短划（手指误碰）不算写了字。
- 拿不准的数字同写字板：只有按答案认后整串正好等于答案才按答案认，这几格不存字模。竖式题不记「能力观察」的书写评分。
- 「擦一笔」撤掉最后写的一笔（答案格、草稿、进位都算）。
- 没写任何答案格就点「写好了」：不判，提示「在蓝框里写答案」。
- 秒答 = 对 且 用时 ≤ 秒答时间 + 1.5 秒（点「写好了」的时间）。用时从示范卡关掉后算起。
- 写对时每格笔迹加进空空的字模（同手写板）。
- 对：格子变绿，照旧 0.8 秒（慢了多停）自动下一题，奖励、矿石、错题集全走原流程。
- 错 / 不会：不描红，右侧滑出「正确写法」（完整竖式，进位退位都写出来）和讲解，有「一步一步看」按当前这道题重放示范；点「继续」下一题。

## 四、示范卡
- 三种版面各自第一次出现时，先放示范卡：用另一组数（加 325 + 148，乘 23 × 14，除 96 ÷ 4），先摆题，再从个位（除法从最高位）一步一步写、标进位退位，每步一句话、2.8 秒一步，正在用的数涂黄。
- 「我会了，开始写」关掉；看过记在本机（`speedmap.vertdemo`），不再自动出；右边「看示范」随时再看。示范期间不计时。
- 语音：暂不做（Ben 11-07）。

## 五、不变的
- 进度数据结构不变，不需要迁移；示范看过与否只存本机一个键。
- 手机、口答、其他题型的流程一个字不改。
- 英文日：页面字和示范每一步的句子都有英文（`i18n.js`）。
