# v3 改动说明（给 Ben 看的白话版，门 6，2026-10-28）

> 只改了预览路径 `v2/`，**正式版（根目录 `index.html`，空空现在在用的）一个字没动**，没有推送。

## 改了什么
1. **首页变成一座岛**：6 块地（看数、分合、数位、比大小、数线、秒答地图），每块一条颜色条和"亮了几格"。左边一个大按钮「开始今天的练习」，系统自己排好 10 分钟。
2. **第一次打开先摸底**：约 3–5 分钟，会的格子直接点亮，不从头做已经会的。中途关掉，下次接着测。
3. **今日练习**：先复习到期错题 → 学一点新的 → 练熟已经会的 → 有余力再学新的。每学一个新技能前先放一张 3 秒的「学一学」示范动画。
4. **三种作答**：手写（和 v2 一样）、两张大卡片点大的那个、在数线上插旗子。
5. **答错有图解**：比如过十准备画两个十格框，从 5 里挪 2 个凑满 10；前后数画数线跳 1 个十。答完照着描一遍，或 3 秒自动下一题。
6. **技能组地图、错题本（按组）、家长区周报**（这周练了几天、每天几分钟、点亮几格、最久没练的技能几天）。
7. **秒答地图**：v2 的整个首页原样搬进"秒答地图"这块地，加减练习、摸底、Boss 关都照旧。
8. **意外情况都有兜底**：切后台自动暂停（回来原题重出）、两个页面同时开着会停一边、出错有「哎呀，卡住了」页、存不了进度有提示条、正式版上线后旧预览页自动停写。

## 进度安全（最重要）
- 秒答进度在三个地方（正式版 v1、预览、以后的新正式版）**按格子取颜色最高的合并**，哪边练的都不丢。
- 每天第一次打开会留一份"好存档"；存档坏了自动用它恢复，坏的原文另存一份，**绝不覆盖原存档**。
- 导入备份改成"只会变多，不会变少"；真要整份覆盖，在「更多」里。

## 怎么验证的
- `npm test`：122 个测试全过（排课规则、升级、迁移 10 条、题面图解、页面脚本一致）。其中 15 处关键规则做过"故意改坏 → 测试变红"的反向验证。
- 排课模拟（8 个种子，120 天）：一般孩子 35 天（最差 43 天）19 个理解技能全部深红；每天用时中位数 10 分钟。
- 真浏览器（932×430 横屏）走完：首次 → 摸底 → 今日练习（手写、点选、数线、示范卡、对错反馈）→ 结算 → 地图 → 错题本 → 家长区 → 秒答地图练习；暂停、返回手势、另一个页面、出错、存不了进度、新版上线。控制台 0 报错。手写识别：程序画的数字 18 / 18 认对。
- 速度：打开 19 毫秒，页面切换 ≤ 17 毫秒，判题 2 毫秒，整页 196 KB。

## 可能影响什么
- 预览版（`/v2/`）的首页完全变了；空空如果在用预览版，会先摸底一次。
- 第一天如果孩子错得多（合格率不到 80%），可能三五分钟就"今天练完啦"——这是有意的：今天吃力就不再加新内容。

## 怎么退回
`v2/` 是预览路径，正式版没动。要退回只需 `git revert` 这几次提交，或者不把 `v2/` 换到根目录。
