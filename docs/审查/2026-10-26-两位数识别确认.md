# 两位数总弹识别确认 · 修复审查（2026-10-26）

## 起因（Ben 真机截图）
写「86」时 8 被认成 0/8 拿不准 → 弹「你写的是？」。两位数只要有一位两可就弹窗，几乎题题弹；经弹窗的题不算秒答。

## 修法
- `INK.resolveWith`：拿不准的那一位，前两名里有答案要的数字、且拼起来正好等于答案 → 直接认，不弹窗，可算秒答。否则照常弹窗。
- 脚本引用加 `?v=N` + 脚本指纹测试（实测踩坑：浏览器缓存旧 ink.js 配新页面 → 一写字就报错，孩子手机同样会遇到）。
- 页面调用的 `C.xxx / I.xxx` 必须在模块里存在（测试）。
