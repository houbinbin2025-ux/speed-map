## 各重点核对小结

1. **§6.2 首启带预览键**：主路径成立；预览键缺失 / 损坏 / 含旧编号、秒答错题、上线后旧 `/v2/` 标签页都没写（B2 阻断、B6）。带过来的新板块错题和 `S.boards` 来自同一份预览存档，本身是一致的；不一致只会出在编号改过的情况（B6 ③）。
2. **§6.3 存档损坏**：与 §6.2 的"没有存档"路径矛盾，回退会丢上线后的进度（B4）；只读运行孩子不知道、且必须显式关掉保存（B5）。预览期损坏影响小（秒答本来就从 v1 读）。
3. **§2.3 推荐规则**：顺序和取舍已无歧义；"完成一批"的定义和秒答不限题、长按结束冲突（B3）。
4. **§3.3 / §3.4 "5 次"可达性**：实测现有配题在"题型都练过没亮"时一批只出每个题型 2 次、整批会缩短；一天 1 批新板块达不到 5 次（B1 阻断）。分合世界 4–5、数线"一天 5 次"同样受影响。
5. **返回手势 / 暂停 / 校准**：历史栈规则要改成"按当前页查表"（B7）；校准页返回必须丢弃半份校准（B8）；已判题后切后台要先记录（B11）；暂停卡片上的返回见 B23。
6. **编号 / 卡数 / Boss 键**：§3、§6、§9 三处一致（看数 31、分合 45 + 7、比大小 8、数线 4；Boss 键世界数与各板块世界数对得上）。
7. **速度预算与验收**：可测；两处"谁测"要调（B21）。B1 必须补一条"每天 1 批能点亮"的验收，否则 §9 测不出这个问题。
