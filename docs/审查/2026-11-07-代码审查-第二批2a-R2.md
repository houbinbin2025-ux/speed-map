## 【建议】

- **B1 `floorOf` 也和冻结级别取大，并且限定范围**：`engine.js:52` 改成 `const floorOf = S => Math.max(validLvMax(S), frozenLevel(S))`，其中 `validLvMax` 只接受 0–15 的整数。这样导入后、第一次练习前也不会低一级，也能挡住 99 或负数这样的坏值。`core.js:408` 的 `importMerge` 里，对 `lvMax` 也先做 `Number.isInteger` 判断再取大。补一条测试：导入后不练习，直接比较 `autoLevel`。
- **B2 能力观察面板对坏数据没有保护**：`index.html:1970` 直接读 `v[0]`、`v[1]`、`v[2]`。如果导入的备份里 `introStat` 某一项不是数组，面板会显示「undefined 题」，但不会报错。可以加一句 `Array.isArray(v)` 过滤。
- **B3 `taught()` 会让部分技能永远不进挑战**：`gems.js:252` 只认 `c:` 概念。说明书 §2 写过，手选过第 10 级以上的孩子看过旧的 3 秒「学一学」，其中平均数、公因数公倍数以后不会再出讲解卡。对这些孩子来说，这两个概念的技能就永远进不了限时挑战和双倍挑战。另外，摸底判为会（`S.known`）的技能，也要等同概念的其他技能出过讲解卡才进挑战。建议改成概念已看过，或者这个技能已看过示范卡、摸底判为会、有任何格子 lv ≥ 1，满足一条就算讲过。
- **B4 CSS 注释放错了位置**：`index.html:338`，「题面带文字……」这条注释现在跟在 `.bcard` 那一行后面，本来是解释 `.eq.tw` 的。只影响阅读。
- R1 的建议 3、4、5 维持不变。
