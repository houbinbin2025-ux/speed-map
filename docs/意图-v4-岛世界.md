# 意图卡 · v4 岛世界（门 0）

## Ben 的原话（10-28 12:06，看了 v3 预览首页截图）
- 「整个设计可以左右移动，不要拘泥一个屏幕。多学习洪恩或者一些游戏的设置。」
- 「这个设计和整个空空岛一点关系都没有。也没有 minecraft 的元素，也没有 minecraft 的那些角色的图片或者场景图。」
- 「重新在交互界面上进行深度的优化。需要注意考虑儿童的学习兴趣和使用平滑度。」

## 我理解的诉求
1. **首页是一个世界，不是一页表格**：空空打开看到的是「空空岛」本身，一座方块浮空岛，可以左右拖着逛，6 个板块是岛上 6 个地方（草原、矿洞、村庄、双塔、铁轨、高塔）。
2. **有角色、有场景**：空空自己是岛上的方块小人，进度长在场景里（方块一级一级亮起来），不是进度条。
3. **练习页也在岛上**：答题时背景是这块地方，答对 = 挖到一块方块，结算 = 方块飞回岛上。
4. **顺滑**：拖动跟手、有惯性，切换有过渡但不拖沓；手机上 60 帧。
5. **不变的底线**（v3 意图卡继续有效）：学习效果优先，排课和判题逻辑一律不动；游戏化只服务于「进步看得见 + 完成的仪式感」，不加和练习无关的环节；一屏一个主动作。

## 和 Minecraft 的关系（需要 Ben 知道）
Minecraft 的角色（史蒂夫、苦力怕等）、官方贴图和截图是 Mojang 的版权素材，这个页面挂在公开网址上，不能直接用。做法：**用同一种「方块世界」画风自己画**——草方块、泥土、石头、矿石、方块树、矿车铁轨、方块小人和方块小狗都是原创像素画（代码画的，0 依赖、0 版权风险），空空一看就是「我的世界那种」，但没有一张是照抄的。
