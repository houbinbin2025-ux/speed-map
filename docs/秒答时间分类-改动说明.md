# 秒答时间按难度分类 · 改动说明（Ben 11-08）

> Ben：难题和简单题的秒答时间应该不同，需要把题目分类处理。
> 代码：`v2/skills.js`（`K.FAST_CLASS` 分类表、`K.fastClass` 归类、`K.fastMs` 按类算时间）、`v2/core.js`（两位数口算卡的时间）、`v2/index.html`（题库页说明）。测试：`tests/fastclass.test.js`。

## 结论
1. **所有题型分成 7 类**，每类有自己的「想的时间」范围；新题型定的时间不合它那一类，测试会拦。
2. **多位笔算不再一个题型一个死时间**：按这道题现算。248 + 568（两次进位）比 213 + 341（不进位）多给 3 秒；乘法、除法同理；竖式中间要写的积、余数、进位也算写字时间。整个题型的平均时间和原来差不多（±15% 以内，测试锁住），只是把难的和简单的拉开。
3. **两位数加两位数、减两位数的口算卡各多 1 秒**（不进位 3→4 秒，进位 5→6 秒），因为要算十位和个位两次。空空 11-08 的数据里这一档秒答最少。
4. 其他题型的时间一个都没动；个人写字速度、英文日读题多给一半，照旧。
5. 口答时多位笔算的答案不用写，但竖式中间的数（积、余数、进位）也得算出来记住，所以这部分时间口答照样给；口答平均也在原来 ±15% 以内（测试锁住）。
6. 已知局限：两位除数的除法（`speed:g13:div2`）题库里商都是两位，所以 200 道题都是同一个时间（24 秒想 + 写字），比原来多 3 秒；以后题库加了一位商或三位商的题会自动拉开。

## 改了什么（白话）
- 秒答时间还是「想 + 读题 + 写字」三段相加，变的是「想」这一段：
  - 口算卡、多位笔算：看这道题本身（进不进位、几位数）现算。
  - 其他题：按题型定（原来那张表，已按步骤数定），现在每个题型都挂到一类下，类有上下限。
- 「写字」这一段：多位笔算除了答案，竖式中间写的数（乘法的两行积、除法每一步的乘积和余数、进位）也按空空测到的写字速度算。
- 家长区题库页：多位笔算的秒答时间显示成范围，例如「24.5–33 秒，按进位和位数」。

## 可能影响什么
- 空空现在练的 10 / 20 以内、钟面、比大小、看图题：**没有变化**。
- 50 / 100 以内两个两位数的口算卡：更容易算秒答，点亮和下架会快一点。
- 三四年级竖式题（空空还没练到）：简单的题秒答时间变短一点，难的变长；平均不变。
- 碎片：另一个会话算每题有效时间时用的就是 `K.fastMs`，会自动跟着变。用 iPad 备份跑 `tools/sim-gems.js` 10 天，改前改后每种玩法的碎片数几乎一样（差 0.1–0.3）。
- 排课节奏：`tools/sim-engine.js` 120 天模拟，强 / 一般 / 弱三种孩子都没有卡死。
