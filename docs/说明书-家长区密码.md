# 说明书 · 家长区密码（F 模块，2026-11-09）

> Ben 原话（中控 11-09 转）：「家长区设置一个秘密：123456，进入的时候要输入。」

## 这是什么，不是什么
- **是**：防孩子误入家长区的锁。空空长按齿轮 2 秒后，要输 6 位数字才能进；输不对进不去，也就改不了难度、清不了进度。
- **不是安全防护**：网页源码谁都能看。源码里只存密码的 SHA-256 哈希（不写明文），但 6 位数字的哈希能被穷举，懂行的人也能直接改页面绕过。不要把它当成保护隐私或账号的密码。

## 规则
| 项 | 规定 |
|---|---|
| 密码 | 6 位数字；源码只存哈希 `v2/lock.js` 的 `HASH`。暂不做改密码功能（以后要加：设置入口放在家长区里，新哈希存进度设置里，旧哈希作兜底） |
| 什么时候问 | 每次打开 App 或页面后，第一次进家长区时问。输对后这一次打开期间不再问；刷新页面、关掉 App 再打开，要重输。解锁状态只放内存，不进任何存储 |
| 锁住什么 | 家长区和它的子页：能力观察、错题分析、题库（`LOCK.SCREENS`）。App 注入的「界面大小」「方块世界时长」两块面板都在家长区里，跟着锁住 |
| 入口 | 唯一入口是首页齿轮长按 2 秒。另在切换页面的 `show()` 里兜底：没解锁时，任何地方要切到上面这些页面，一律先问密码，所以以后新加入口也不会漏锁 |
| 输错 | 提示「密码错误」，圆点抖一下、清空重输。不锁死、不计次数 |
| 输入方式 | 屏幕数字键盘（1–9、0、删除、取消），每个键至少 72 × 56 点；外接键盘可直接打数字，退格删除，Esc 取消 |
| 取消 | 关掉浮层，留在原来的页面 |
| 语言 | 浮层孩子看得到，跟单双日走：英文日显示 Parent passcode / Enter the 6-digit parent passcode / Incorrect passcode / Cancel / Delete |

## 没锁的（不归这次）
- **两指捏合改界面大小**（App 里任何非答题页都能捏，`ios/App/App.swift` 的 `__kongPinch`）：这是改显示大小的手势，不是进家长区的入口，这次不锁。要锁的话归中控（iOS 外壳）。
- **方块世界自己的「家长确认」**（另一个仓库，C 模块）：不在数学岛里，这次不动。
- **测试模式 `#test`** 照样要输密码；走查脚本统一用 `PIN(pg)` 输入。

## 测试
- 单元 `tests/lock.test.js`：SHA-256 和 node 的 crypto 逐个对照；源码里没有明文；输对解锁、输错不解锁也不锁死；家长页没解锁被拦；新建一把锁（相当于刷新）又锁上；解锁状态不进存储。
- 走查 `tools/e2e/e2e-pin.py`：5 种横屏尺寸（667×375、844×390、932×430、1194×834、1366×1024），每个键都用 elementFromPoint 查一遍，确认点得到；依次走输错、连错、删除、输对、同一次打开不再问、刷新后要重输、取消、没解锁直接触发子页入口被拦、键盘输入；英文日；App 打包页面里方块世界面板要先输密码才看得到。竖屏不测：整页会被「把屏幕横过来」盖住。
- 原有 11 个要进家长区的走查脚本，长按齿轮后都加了 `PIN(pg)`。
