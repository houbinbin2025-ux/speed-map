# 调研 · 家与奖励（门 1）

| 来源 | 说什么 | 我们怎么用 |
|---|---|---|
| [Deci, Koestner & Ryan 1999](https://home.ubalt.edu/ntygmitc/642/Articles%20syllabus/Deci%20Koestner%20Ryan%20meta%20IM%20psy%20bull%2099.pdf)（128 个实验的元分析，《心理学公报》） | 实物奖励会明显削弱内在动机；[Cameron & Pierce 1994](https://pmc.ncbi.nlm.nih.gov/articles/PMC2731358/) 认为影响有限，学界有争论 | 不发能兑换的东西；奖状写清"会了什么"，不写"你真棒" |
| [Mathseeds 奖励说明](https://mathseeds.helpjuice.com/faqs/what-motivatorsrewards-are-available-for-students-in-mathseeds) | 学完得橡子，可花在树屋和形象上；证书可打印带回家 | **选**：家 + 可打印奖状。**不选**：货币和商店 |
| [Mathseeds 第三方评测](https://screenwiseapp.com/guides/mathseeds-app) | 孩子可能乱点到答案，只为拿橡子 | 奖励只看格子颜色（隔天还会），乱点拿不到 |
| [Prodigy 课程资源评述](https://ecampusontario.pressbooks.pub/techinthecurriculum/chapter/prodigy/) | 孩子在装扮和非学习内容上花时间是负面因素；引 2020 年研究建议限制装扮时间 | **不选**：不做无限装扮；家里没有计时玩法，只能看、点、摆放 |

本次检索未找到儿童专项和"意外奖励"研究的原文，以下两条是**推论**：隐藏道具（🔍意料之外不易让孩子只为奖励而练）；可摆放（🔍自己决定位置，增加归属感）。门 5 真人试观察。

## 定的机制
- **奖状 25 张**：称号 + 画面。每个地方学会 / 附魔记牢两张（秒答 = 打败 / 驯服 Boss）、累计天数 4 张、改错 3 张。
- **伙伴图鉴 38 只**：每个技能一只（学会解锁，全部深红 = 附魔版），可带回家走动。
- **道具 36 件**：功能道具 + 盔甲 4 件 + 隐藏 3 件 + 摆设 15 件。
- **战利品箱**：新奖励不直接摆好，自己开箱（内容固定，不抽奖）。
- **矿物柜**：铁锭 / 金锭 / 钻石 = 淡黄 / 淡红 / 深红的格子数，让"隔 3 天还会"变成看得见的钻石。
- **不做**：商店、货币、抽奖、连续打卡（断了不扣）、排行榜、看广告、靠快慢排名。
