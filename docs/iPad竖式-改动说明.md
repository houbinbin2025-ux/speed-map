# iPad 竖式 · 改动说明（白话，2026-11-07）

## 改了什么
- **iPad 上做三位数加减、乘法、除法题，换成竖式版面。** 共 7 种题：三位数加减、乘一位数、两位数乘两位数、三位数乘两位数、除以一位数、两位除数。
  - 竖式写在中间的卡片上，答案一格写一个数。
  - 有写进位、退位的小格，乘法和除法还有草稿条。草稿和进位只给孩子自己算，不判。
  - 写完点「写好了」才判。原来停笔就自动交，多位数算到一半停下来想，会被提前交掉。
  - 写错一笔点「擦一笔」，只撤最后一笔。手指误碰的小点不算写字。
  - 答案要从最右边一格（个位）写起。往左挪了，会提示「个位写在最右边的格子里」。
- **第一次见某种竖式，先放示范。** 加、减、乘、除各一张，用另一组数字：
  - 先摆出整道题，再从个位一步一步写（除法从最高位开始）。
  - 每一步配一句话，正在用的数字涂黄。
  - 点「我会了，开始写」才开始计时。以后点右边「看示范」可以再看。
- **答错或点「不会」，不再描红。** 右边滑出这道题的正确写法，进位、退位、部分积都写出来，还有原来的讲解。
  - 点「一步一步看」，会拿这道题本身再演示一遍。
  - 点「继续」到下一题。
- **答对和原来一样**：格子变绿，自动下一题，矿石、宝石、秒答、错题宝箱都照旧算。秒答时间比原来多给 1.5 秒，留给点「写好了」。
- **（11-08 补）剩下的 38 种三四年级手写题也换成 iPad 版面**：题在上面，中间格子纸打草稿，下面蓝框写答案，点「写好了」才判。
  - 递等式（四则混合、运算律）：多两行「=」，第一次先看示范，答错按运算顺序一行一步写出正确写法。
  - 填空（比如 7.0 − 4.2 = 2.□）：方框在数字中间就只有一个蓝框；答错显示填好的整个算式。
  - 应用题：题干放大、可以点喇叭听，答错看讲解里的算式。
- **手机、口答、一二年级的题都没变。**
- **英文日**：竖式版面和示范的每一句都有英文。

## 可能影响什么
- 只影响 iPad（屏幕短边 ≥ 700 点）上这 7 种题。iPad App 和 iPad Safari 都生效。
- 识别改成一格一格认。写对的时候，每格的笔迹会加进空空的字库，和写字板一样。
- 进度数据没改。「哪种示范看过了」只记在这台设备上。

## 怎么退回
- 要关掉竖式：在 `v2/index.html` 里把 `vertOn` 那一行改成返回 `false`，跑 `node tools/bump-version.js`，推送，再跑 `bash ios/release.sh`。
- 要整个撤掉：`git revert` 这次提交。

## 验证
- `tests/vert.test.js`：7 种题全部题目都排得出竖式，得数和题库一致，示范每一步都有中英文，判题规则都覆盖到。
- `tools/e2e/e2e-vert.py`：在 iPad Safari 尺寸、iPad App 尺寸、iPhone 尺寸上真写一遍。覆盖判对、判错、不会、最高位写 0、没写就交、示范、「一步一步看」、英文日。
