# 题库改动说明（给 Ben 看的白话版，2026-10-29）

> 只改了预览路径 `v2/`，**正式版（根目录 `index.html`，空空现在在用的）一个字没动**。

## 改了什么
1. **题目变成一份独立的题库**（`v2/bank.js`，共 5512 道）。原来一半的题是程序每次临时随机拼的，现在每道题都写在题库里，出题只从题库里取。
2. **每个技能的难点都收进去了**。题少的题型（≤ 400 种）全收；题多的按难点分层抽 120 道，每种难点都有足够多的题：
   - 两位数比大小：「41 和 38」这种十位大、个位小的有 42 道，这是只看个位就会选错的题。
   - 前后数：「39 多 1」这种要跨十的题全收。
   - 秒答两位数加减：加数、减数的每个个位都出现；「40 − 3」「27 + 13 = 40」这种最难的题至少 20 道。
3. **比大小题，大的数左右各一半**。原来抽出来的题大数偏在右边，孩子一直点右边也能过关。
4. **出题像发牌**。同一类题把题库里的题一轮发完才重新洗牌，一轮里不会重复；发到哪一张记在进度里，关掉页面明天再开也接着发。120 道的题型要连练大约 20 天才会重来一遍，背不出答案。
5. **秒答答错时有讲解了**。原来只显示正确算式，现在会讲怎么想，例如：
   - 「28 先加 2 凑成 30，再加 3，是 33」
   - 「40 拿出 1 个十：10 − 3 = 7，30 + 7 = 37」
6. **50 以内的进位加法，要先会 20 以内的进位加法**（28 + 5 要用到 8 + 5），退位减法同理。原来只要求先会数位。
7. **家长区第一块就是「题库」**。点板块（看数、分合、数位、比大小、数线、秒答），就能看到：
   - 每个技能学什么、怎样算学会、怎么教、要先学会什么（学没学会都标出来）。
   - 每类题能出多少种、题库收了多少道。
   - 全部题目：固定题按空空现在的颜色上色，在错题本里的题标红点。
   - 点任何一道题，能看到孩子看到的题面和答错时看到的讲解。

## 进度安全
- 每张卡、每个题型的编号一个没改；错题本里题目的存法也没改，连字段顺序都一样。已用改造前的代码拍了快照，测试逐字比对。
- 以前随机出的、不在新题库里的旧错题，照常复习。家长页把它们单列成「题库外的旧错题」。
- 以后改题的规则写进了题库文件：编号只增不删；卡的题目不改，要改就换新编号；题型的题可以增删。

## 怎么验证的
- `npm test`：142 个测试全过。新增的题库测试检查五条「够学会」标准：
  1. 每种难点的题量不少于下限。
  2. 题量够，不会背出答案。
  3. 每道题的答案用另一套算法重算一遍。
  4. 每道题都能画出题面和讲解。
  5. 题目不超出原来的范围。

  另外检查了旧进度、旧错题不丢，比大小左右平衡，发牌一轮不重复，3806 道秒答题的讲解得数逐题核对。
- **反向验证**：故意把题库改坏 5 种方式（答案改错、删题、改难点标签、加越界的题、改卡编号），测试都会变红。
- **遮盖扫描**：6 种 iPhone 横屏尺寸，0 处遮盖。
- **真浏览器走查家长题库页**：932×430 和 667×375 两种尺寸，6 个板块都展开、每类点题预览、右滑返回，0 报错。
- **两轮新上下文独立审查**：第 1 轮不通过（比大小大数偏右、抽样漏掉整类题等），改完后第 2 轮有条件通过，它提的阻断（家长页进度显示错）和 3 条重要问题也已修好并验证。记录在 `docs/审查/2026-10-29-题库审查.md`。
- **孩子练习走查**：今日练习 24 题、手写识别 18/18、暂停、右滑返回、自由加练、秒答地图都正常，0 报错。

## 可能影响什么
- 比大小两位数答错时的小数线，改成只画这两个数附近的那几个十（例：17 和 21 画 10—30），挨得近时两个数字上下错开。
- 秒答 L3（50 以内）的新题要等 L2 的进位、退位世界学会后才出。已经在练 L3 的不受影响：前置只管「学新的」，已开始的照常练。
- 原来的 `engine.test` 里有一条测试判断得太粗，换了出题后被误判失败。已改成按说明书原意判断，并验证过关掉排课规则后它照样会报错。

## 怎么退回
`v2/` 是预览路径，正式版没动。要退回就 `git revert` 这次提交。题库数据都在 `v2/bank.js`，旧的出题代码在 git 历史里。
