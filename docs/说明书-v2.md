# 说明书 · v2（横屏手写 + 错题集）

> 档位：**可交付**（孩子每天独立用，交互和数据都要过线）。对标水位：交互参照 Duolingo ABC / 洪恩数学的"一屏一动作"，逻辑稳定性参照 v1 现有标准。
> 范围：A 横屏手写 + B 错题集 本轮做完上线；C 小学全路线本轮只出 `路线图-小学数学.md` + 数据结构预留，内容下一轮起逐级填。

## 0. 关键决定（我定的，附理由）
| 决定 | 理由 | 不这样的后果 |
|---|---|---|
| 手写识别用**个人笔迹校准**（首次 0–9 每个写 3 遍，之后自动积累），本机算 | 只服务空空一个人，用她自己的笔迹做模板最准；不联网、无依赖 | 通用模型对儿童笔迹误判多，孩子写对被判错会直接挫败 |
| 只写一遍，不做"写 + 再按键盘" | 双输入每题多一步，秒答用时被拉长，熟练度失真 | 孩子嫌麻烦，用时数据不可信 |
| 识别没把握时弹「你写的是 7 还是 1？」两个大按钮 | 兜底误判，又不增加正常路径步骤 | 误判无法纠正 |
| 手写与口答**共用一张地图**，限时分开算：手写限时 = 口答限时 + 1 秒 + 每多一位数再 + 1 秒 | 孩子只认一张地图；手写慢是动作慢不是不会 | 两张地图孩子迷糊；同限时手写永远亮不了 |
| 同一个页面两种模式：横屏手机默认手写，竖屏/平板保留口答 | 不拆两套代码、两份进度 | 两份进度互相打架 |
| 新版先放 `v2/` 预览路径，数据键 `speedmap.v2`，首次打开从 `speedmap.v1` 复制 | 线上 main 即孩子在用；预览期不能写坏正式进度 | 测试时把空空的进度写乱 |

## A. 横屏手写
**布局（横屏）**：左半屏 = 题目大字 + 顶部（退出 / 第几题 / 倒计时）；右半屏 = 手写板（米黄底、淡格线），右下角两个小按钮「擦掉」「不会」。
**作答流程**：
1. 出题 → 计时开始。
2. 空空在手写板上写答案；最后一笔抬起后停 0.9 秒自动提交（写的是答案前半截、比如答案 12 只写了 1，就多等到 1.5 秒）。用时 = 出题到最后一笔抬起，不含等待。
3. 识别：笔画按左右位置分组，每组识别一个数字，左到右拼成答案。
4. 判定：
   - 识别 = 答案 → 答对（限时内显示「⚡秒答」，超时显示「✓」）→ 0.8 秒后自动下一题。
   - 识别 ≠ 答案、且没把握（前两名候选分数接近）→ 弹「你写的是 X 还是 Y？」→ 按她选的判。
   - 确定答错 → 显示正确答案，手写板上淡淡显示这个数字，**照着描一遍**（练写字）→ 自动下一题；这道算式进错题集。
5. 「不会」= 直接按答错处理（显示答案 + 描一遍）。
**笔迹校准**：第一次进手写模式进入校准页：「教我认识你写的数字」，0–9 每个写 3 遍（约 2 分钟），有进度条。之后每次高把握识别正确的笔迹自动加进模板（每个数字最多 15 个，新换旧）。家长区可「重新校准」。
**竖屏时**：手写模式提示「把手机横过来」+ 一张横屏示意图。

## B. 错题集 + 记忆曲线
- **进错题集**：答错（手写判错 / 选「不会」/ 口答模式家长点「答错了」）的**具体算式**（如 27+15，题型级别也记具体数字）。超时但答对不进（这由地图颜色管）。
- **复习间隔**：1 → 2 → 4 → 7 → 15 天（记忆曲线近似）。到期复习答对且限时内 → 进下一档；答错 → 回第 1 档；过完 5 档 → 「已掌握」，移出待复习。
- **插进每日练习**：当天到期的错题排在开头 3 道"热身题"之后，每轮最多 6 道（再多会挫败），其余顺延到下一轮。
- **错题集页**：顶部「今天要复习 N 道」+ 大按钮「现在复习」；下面三栏：待复习 / 复习中（显示第几档、下次日期）/ 已掌握。
- **首页入口**：「错题本」按钮，有到期题时显示红点数字。
- **结算页**：多一行「新进错题本 N 道 · 今天复习过关 M 道」。
