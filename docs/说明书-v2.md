## 0. 关键决定（我定的，附理由）
| 决定 | 理由 | 不这样的后果 |
|---|---|---|
| 手写识别用**个人笔迹校准**（首次 0–9 每个写 3 遍，之后自动积累），本机算 | 只服务空空一个人，用她自己的笔迹做模板最准；不联网、无依赖 | 通用模型对儿童笔迹误判多，孩子写对被判错会直接挫败 |
| 只写一遍，不做"写 + 再按键盘" | 双输入每题多一步，用时失真 | 孩子嫌麻烦，用时数据不可信 |
| 设备 = **iPhone Pro Max 横屏**（约 932×430 点，16 Pro Max 956×440；左右各让出约 60 点灵动岛/圆角安全区）；书写方式未确认前按**手指写**设计 | Ben 10-25 确认机型；手指能写下，触控笔只会更好 | 手写板太小、两位数写不下，孩子弃用 |
| 手机**一律横屏手写**；口答模式收进家长区（家长陪着时用） | 目标第 1 条：孩子一个人能练，判定只能靠手写识别 | 竖屏口答没人判对错 |
| 手写与口答**共用一张地图**；手写限时 = 口答限时 + 实测"写一个数字的中位用时" × 答案位数（实测不到时按每位 1 秒） | 孩子只认一张地图；手写慢是动作慢不是不会，用她自己的速度补偿 | 两张地图孩子迷糊；拍脑袋限时导致永远亮不了或太容易亮 |
| **预览期与上线期分开处理数据**（见下方「数据迁移」） | 预览期空空仍在用 v1，v1 永远是正式进度；上线只迁移一次 | 整份"取较新"会两头互相覆盖，丢错题本或丢孩子进度（R2 阻断 A） |
| 笔迹模板单独存（`speedmap.ink`，预览和正式共用，校准成果带到上线），不进备份；测试模式进度用 `speedmap.v2.test`、笔迹用 `speedmap.ink.test` | 备份保持小；测试笔迹不污染孩子的模板 | 备份过大 Ben 不备份；测试写的字降低识别率 |

### 数据迁移（R2 修订）
- **怎么区分**：页面地址在 `/v2/` 下 = 预览期；在根目录 = 上线期。同一份代码按地址判断。
- **预览期**：每次启动从 `speedmap.v1` **只读**复制一份地图进度到内存；预览中产生的地图进度、错题本写进 `speedmap.v2.preview`，**只在预览里用，上线时丢弃**。v1 一个字都不写。预览页顶部常驻小字「预览版 · 这里练的不计入正式进度」。笔迹校准例外：写进 `speedmap.ink`，上线后继续用。
- **上线期**：首次启动若没有 `speedmap.v2`，从 `speedmap.v1` 迁移一次，写入 `speedmap.v2` 并记 `migratedFromV1At`；之后**再也不读 v1**（旧标签页还往 v1 写也不影响）。`speedmap.v1` 原样保留不删，作为回退备份。
- **退回**：把根目录换回 v1 即可，v1 数据未被改动；v2 期间的新进度可从 v2 导出备份后导入 v1（字段兼容）。
- **测试**：①预览期 v1 有新进度 → 下次打开预览能看到；②预览中练习 → v1 数据不变；③上线首启迁移 → 颜色数与 v1 一致；④迁移后 v1 再被写 → v2 不受影响；⑤迁移只发生一次。

## A. 横屏手写
**布局（横屏）**：左 40% = 题目大字 + 顶部（退出 / 第几题 / 倒计时）；右 60% = 手写板（米黄底、淡格线、不分格），右下角两个按钮「擦掉」「不会」（至少 56×56 点）。
**作答流程**：
1. 出题 → 计时开始。
2. 空空在手写板上写答案；最后一笔抬起后停 0.9 秒自动提交；**已写的位数少于答案位数时，一律等 1.5 秒**（防两位数中间停顿被提前提交）；落下新的一笔就重新计时。用时 = 出题到最后一笔抬起，不含等待。
3. 识别：笔画按左右位置分组，每组识别一个数字，左到右拼成答案。
4. 判定：
   - 识别 = 答案 → 答对（限时内「⚡秒答」，超时「✓」）→ 0.8 秒后自动下一题。
   - 识别没把握（某一位前两名候选分数接近）→ 弹「你写的是 X 还是 Y？」→ **只用来纠正识别**：
     - 候选**只按笔迹排名产生，绝不参考正确答案**（两个候选都不对时就是两个错的）；
     - 两位数**只问没把握的那一位**，有把握的位直接显示（如「你写的是 1■ ，■ 是 3 还是 8？」）；
     - 确认后的结果等于答案 → 算答对，但**不计秒答、不升级**；不等于 → 按答错处理；
     - 经弹层确认的笔迹**不加进模板**；
     - 弹层另有「重写」按钮：两个都不是她写的 → 清空手写板重写这一题，用时照原起点算。
   - 确定答错 → 显示正确答案，手写板上淡淡显示这个数字，请她照着描；**描任意一笔或 3 秒后自动下一题**；本批连续第 2 道错题起不再要求描。这道算式进错题本。
5. 「不会」= 按答错处理。
**笔迹校准**：第一次进入练习先到校准页「教我认识你写的数字」，0–9 每个写 3 遍（约 2 分钟，有进度条），同时记下她写每个数字的用时（用来定手写限时）。之后高把握且答对的笔迹自动加进模板（每个数字最多 15 个，新换旧）。家长区可「重新校准」。
**竖屏时**：提示「把手机横过来」+ 横屏示意图。

## B. 错题本 + 记忆曲线
- **进错题本**：答错（判错 / 选「不会」/ 弹层选了错的 / 口答模式家长点「答错了」）的**具体算式**（如 27+15；题型级别也记具体数字）。超时但答对不进。
- **复习间隔**：1 → 2 → 4 → 7 → 15 天。到期复习：答对且限时内 → 进下一档；答对但超时 → 留原档，明天再来；答错 → 回第 1 档；过完 5 档 → 「已掌握」。
- **插进每日练习（与 v1 机制合并，防难题扎堆；R2 修订为可直接写测试的规则）**：
  - "一批" = v1 的 20 题一批（题数不限模式下一批出完再出下一批）。
  - **难题** = 到期错题 + v1「练习中」单位（练过、还是灰色）。每批难题**合计最多 8 题次**，分配顺序：
    1. 到期错题先占，**最多 4 题次**（每道 1 次，到期早的优先）；
    2. 「练习中」单位填到 8（v1 规则：最久没练的优先、每个 2 次；剩奇数名额时最后一个只出 1 次）；
    3. 「练习中」用不完的名额，再给更多到期错题，总数仍 ≤8。
  - **去重**：一题一卡级别（10/20 以内），错题的卡已在「练习中」→ 不另出，算进该卡的 2 次里，**第 1 次作答算错题复习结果**（第 2 次只算练习中）。题型级别（50/100 以内），错题所属题型已在「练习中」→ 这道错题**顶替该题型的一次出题**（用错题的具体数字），不额外占位。
  - **补满规则**：v1 题型级别题目不够 20 时会重复已选题补满（index.html 第 390–392 行）；v2 改为**补满只用非难题**（已会的、新题）。没有非难题可用时本批可以不满 20，由"题数不限"自动接下一批。
  - **当天不重复**：错题复习一次后（过或不过）下次最早明天；今天新进错题本的题，明天才到期。所以同一道错题一天最多出 1 次。
  - 系列过滤：加法练习只出加法错题，减法同理，混合都出。
  - 到期错题排在开头 3 道"热身题"之后；超出名额的顺延到下一批 / 第二天。
  - **测试场景**：到期错题 0/3/6/10 道 × 练习中 0/1/3/5 个的组合，断言每批难题 ≤8、无重复卡、补满不含难题、系列过滤正确。
- **错题本页**：顶部「今天要复习 N 道」+ 大按钮「现在复习」；下面三栏：要复习 / 复习中（显示第几档、哪天再来）/ 已掌握。
- **首页入口**：「错题本」按钮，有到期题时显示数字角标。
- **结算页**：多一行「新进错题本 N 道 · 今天复习过关 M 道」。
