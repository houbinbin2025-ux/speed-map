# 意图卡 · v5 空空的家（门 0）

## 原话（Ben 11-04）
「空空的房子做一个点进去后的效果，需要有小朋友在学习中获得的各种奖状墙，获得的各种奖励，还有 minecraft 的其他的觉得合适的道具。这是空空主动的需求，你根据我透露的内容洞察下，然后看怎么设计，给我设计原型，我同意后开始落地。」

## 洞察（🔍推论，门 5 真人试时验证）
1. **「主动提」本身是最重要的信号**：空空已经把岛当成自己的世界，想要一个属于自己的地方。岛上 6 个地方都是"去练的"，只有家还点不进去（现在只弹一句"这是空空的家"）。
2. **要的是「我做到了什么，留得住、看得见」**：奖状是学校里最熟悉的荣誉形式，还能给大人看；方块游戏里玩家也会把战利品摆回基地。
3. **一个现成的缺口**：练习时"挖到 N 块矿石"，结算后就消失了。挖了一路，东西却没地方放。
4. **钱已经有两套，缺的不是钱**：线下珠子（换玩具、选晚饭）、空空矿场宝石（换屏幕时间）都是能花的。第三套货币没有必要，还会和这两套打架。**家里的东西一律不能花、不能买、不会减少**——它证明"我会了什么"。

## Ben 第二次反馈（11-04，看第一版奖状后）
「奖状太呆板，一点小朋友的爱好点都没 get 到。重新思考重构下。」

第一版错在：奖状还是学校那一套，写"已学会全部 31 格"，是大人视角。家里线索其实早就有（原 `print/练级成就树.html`，11-08 已归档到 `~/08_归档/print-deprecated/秒答地图-print-snapshot-2026-11-08/`）：世界（草地到末地）、Boss 关、称号、每天看方块游戏视频、联机、盲盒、读相关桥梁书、小狗。
**改法：把"会了什么"翻译成游戏里挣来的东西**
- **奖状 = 称号 + 会动的画面**，小人小狗在画面里：草原牧羊人（羊摆成骰子 5 点）、矿洞矿工、双塔哨兵、铁轨列车长；秒答 = 打败 Boss。数学内容只留一行小字。
- **记牢 = 附魔版 / 驯服**：同一张加紫色流光；Boss 从"打败"变"驯服"，变成站在你身边的小伙伴。"隔 3 天还会"变成孩子一眼想要的东西。
- **奖章 → 伙伴图鉴**：每学会一个技能解锁一只生物（38 只），可以带回家在屋里走（最多 4 只）。
- **领奖 → 开战利品箱**：练完后家门口多一个发光的箱子，自己点开。内容按学习结果固定，不是抽奖。
- 美术全部原创；不用任何现成游戏的角色、怪物造型和名称。
