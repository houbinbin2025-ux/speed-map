## 1. 意图与指标
见 `意图-v3.md`。本版推动**主指标**：4 个理解技能组全部牢固（深红）的天数 ≤ 60 天；**护栏**：每天 ≤ 10 分钟独立完成、练完后剩下的到期错题 ≤ 5 道、在学技能 ≤ 7 天不出现。

## 2. 做什么 / 不做什么
**做**
- **今日练习**：首页一个大按钮，系统排好 10 分钟（复习 → 学新的 → 熟练），跨技能交错出题。
- **摸底定位**：第一次用时约 5 分钟，会的直接点亮。
- **4 个理解技能组**：看数、分合、比大小、数线（共 17 个技能，见 §3.3）。
- 首页改为"岛"：展示所有技能组的进度，可点进去自由加练。秒答地图作为岛上的一块，**保持 v2 全部功能**（级别、世界、摸底、Boss、自由练习）。
- 补齐现有缺口：切后台暂停、出错兜底页、存档损坏不覆盖 + 每日好存档、返回手势、多标签页、日期倒退不升级、一次练习按开始日期记录。
- 家长区周报：每天用时、新点亮、错题情况（意图卡的指标）。

**不做（推迟）**：故事题、模式规律（v4）；钟表、人民币（v5）；图形空间（线下积木）；新技能组的 Boss 关（秒答地图的 Boss 保留）；打印版新地图。

## 3. 孩子怎么用

### 3.1 路径
1. **第一次**：首页 →「开始」→ **摸底**（约 5 分钟，顶部写「看看你已经会什么」）→ 结果页「你已经会了这些！」（亮起的格子闪一下）→ 进入今日练习。
2. **每天**：首页 = 岛 + 大按钮「开始今天的练习」→ 练 10 分钟（顶部一条时间进度条，不显示倒计时数字）→ 结算 →「去贴 1 颗珠子」→ 回首页。
3. 今天练完后大按钮变成「今天练完啦！」，下面一个小按钮「再练一会」（再来一次今日练习，只多 5 分钟）。
4. **自由加练**：岛上点任一技能组 → 技能组地图 →「练这个」（12 题）。秒答地图入口和 v2 一样。

### 3.2 今日练习怎么排（模拟验证过，见风险验证记录）
总长 10 分钟，按时间分 3 段，孩子看到的是一条连续的练习，段与段之间不停：
1. **复习**（最多 5 分钟）：到期错题，到期早的先出，不同技能交错。
2. **学新的**（3 分钟）：
   - 选**前置都已学会、自己还有灰格子**的技能，按 §3.3 的顺序取前 2 个；
   - 一个技能**第一次**出现前，先放一张「学一学」示范卡（见 §3.4），孩子点「我知道了」继续；
   - 如果复习段结束后还剩 **> 10 道**到期错题，今天跳过这一段（时间留给熟练段）。
3. **熟练**（剩下的时间）：今天能升级的格子 → 已学会但还没牢固的格子（颜色低的、最久没练的先），跨技能交错；秒答地图的格子也在这里出。**题型格子一旦被选中出 3 题**（和别的题交错，不连着出），否则攒不够"最近 8 次"（模拟：每次 1 题时一般孩子主指标 75 天，3 题时 50 天）。
- 到 10 分钟后，做完当前这题就结束；中途长按结束也可以，已答的照常记录。
- 一次练习里同一张卡最多出 2 次、同一题型最多 6 次；同一技能不连续出现超过 3 题。

**格子怎么升级**（四档颜色、只升不降、一天最多一级、淡红到深红隔 ≥ 3 天，同 v2）
| 格子 | 灰 → 淡黄 | 淡黄 → 淡红 → 深红 |
|---|---|---|
| **卡**（一道固定的题） | 合格 1 次 | 合格 1 次（同 v2 的天数规则） |
| **题型**（一类题，数字每次不同） | 最近 8 次（可以跨天）合格 ≥ 7 次 | 同左，每升一级清空重新数 |

**合格标准**："先对后快"
| 技能组 | 灰的时候 | 淡黄以后 |
|---|---|---|
| 看数 | 对 | 对（不计时，闪现本身就是"一眼"） |
| 分合 | 对 | 对且在限时内（3 秒 + 写一个数字的用时） |
| 比大小 · 点选 | 对 | 对且 ≤ 2 秒（从按钮能点的那一刻算） |
| 比大小 · 前后数 | 对 | 对且在秒答的限时内 |
| 数线 | 在合格误差内 | 同左（不计时） |
| 秒答地图 | 同 v2（不改） | 同 v2 |

**错题本**：任何答错（含「不会」）的具体题进错题本，1/2/4/7/15 天回炉，同 v2。复习过关 = 按这个格子**当前阶段**的合格标准。

**摸底定位**（对标 ALEKS 的首次诊断，简化版）
- 只摸 4 个理解技能组（秒答已有进度）。
- 每个技能组从**最难的技能往下**测：抽 3 题，3 题都合格（不计时）→ 这个技能和它所有前置技能的格子全部点亮成**淡黄**，这一组测完；否则测下一个更简单的技能。
- 最多 5 分钟、最多 40 题；时间到了没测到的技能保持灰色，以后在今日练习里正常学。
- 只点亮到淡黄（以后照常要另一天、隔 3 天才升），所以摸底判错了也会被后面的复习纠正。
- 家长区可「重新摸底」（只会点亮，不会让已亮的变灰）。

### 3.4 每种题长什么样（左边题目，右边作答，同 v2 横屏布局）
| 技能组 | 题目区 | 作答区 | 答错时的图解 |
|---|---|---|---|
| 看数 | 图案闪现 1.5 秒后消失（家长区可调 1 / 1.5 / 2.5 秒）；左下「再看一次」（用了这题不升级、不进错题本） | 手写数字 | 重新显示图案 + 数字；十格框按 5 一组标出：「5 和 2，是 7」 |
| 分合 1–3 | **分合图**：上面一个圆是整体，下面两个圆是部分，空的圆就是要写的 | 手写数字 | 十格框画出两部分（7 个实心点 + 3 个空格） |
| 分合 4–5 | 算式，空格画成方框 | 手写数字 | 同上 |
| 比大小 1–3 | 两个数 | 左右两个大按钮（高 ≥ 140 点、宽 ≥ 300 点，按可视高度自适应），点一下立即判 | 两个数放到小数线上，大的在右边亮起：「74 在 47 的右边，74 大」 |
| 比大小 4 | 「比 37 多 10 是 □」 | 手写 | 数线上从 37 跳到 47 |
| 数线 | 「把旗子插到 **7** 的位置」 | 线长约 760 点，两端距安全区 ≥ 24 点，只标两端（数线 4 加标 50）；手指在线上下 60 点内按下出现红旗（画在手指上方），可拖动，抬手停 1.2 秒自动提交；屏幕左右边缘 20 点内不接收触摸 | 正确位置插绿旗，箭头标出差多远：「再往右一点」 |

**「学一学」示范卡**（每个技能第一次出现前一张，具体—图形—抽象）：一段 3–5 秒的自动动画演示这类题怎么想（例：分合 —— 5 个圆点分成 2 个和 3 个，再变成分合图），下面大按钮「我知道了」。

**防乱点**（比大小点选）：最近 5 道点选题错 ≥ 3，或连续 3 题都在 0.4 秒内作答 → 「慢一点，看清楚再点」（2 秒后自动消失）；这次练习剩下的点选题，数字出现 1 秒后按钮才能点，2 秒限时从能点那一刻算。

**孩子看到的字**
| 情况 | 文字 |
|---|---|
| 卡第一次合格 | 「✓ 对了！点亮了」 |
| 题型合格、还没升级 | 「✓ 对了！」 |
| 题型升级 | 「✓ 点亮了！」 |
| 淡黄以后，对且快 | 「⚡ 又对又快！」 |
| 淡黄以后，对但慢 | 「✓ 对了 · 再快一点就能升级」 |
| 不计时的合格 | 「✓ 对了！」（数线：「很接近！」） |
| 答错 / 不会 | 图解 + 「记住它，下次再来」 |
- 技能组地图上的题型格子显示一行小字「最近 8 次对了 6 次」，不用圆点。

**返回手势实现（"哨兵"写法）**：页面启动时 `history.pushState` 压一条只带标记的记录（不改地址，`#test` 不受影响）；右滑触发 `popstate` → 按**当前页**查上表"返回"列处理 → 立刻再压回一条。页面切换本身不压记录。验收：真机在练习中、首页各连续右滑 5 次都不离开；万一离开，进度每题已存，回来刷新到首页（写进改动说明）。

### 6.2 预览期 / 上线期
- **预览期**：每次启动从 `speedmap.v1` 只读复制**秒答部分**（`cards / boss / log / level`）；其余（`S.skills`、全部错题、`placedAt`、`daily`、`stats`、设置）保留预览键里的值。家长区可导入，但只导入秒答以外的部分。
- **上线期首启**（没有 `speedmap.v2`）：①秒答部分从 `speedmap.v1` 迁移（同 v2）；②读 `speedmap.v2.preview`：存在且能读 → 带过来秒答以外的全部（不认识的编号丢掉）；不存在 → 从空开始（第一次打开会摸底）；读不了 → 原文存进 `…broken`，从空开始，家长区提示；③写入 `speedmap.v2`，记 `migratedFromV1At`；之后不再读 v1 和预览键。
- **上线时 `/v2/`**：`/v2/index.html` 换成一句自动跳转到正式地址。另外，**v3 预览页自己也会检查**：启动、回到前台、收到存储变化时，只要发现 `speedmap.v2` 已经存在（说明正式版已经上线并首启过）→ 立刻停止写入，显示 12f「新版已经上线了」+「去正式版」。这样没刷新的旧标签页也不会再写预览键（修 R2 第 3 轮 N2）。
- **向下兼容**：v3 备份导入 v1 不报错（已核实：v1 只检查 `cards` 是对象）。

### 6.3 存档读不了
主存档解析失败或缺 `cards`：
1. 原文复制到 `…broken`。
2. `…good` 能读 → 用它恢复（最多回退一天），家长区提示「存档读不了，已用昨天的备份恢复」。
3. 没有可用的 `…good` → 按 6.2 的"没有存档"路径。
4. 第 1 步复制失败（空间满）→ **只读运行**：内存里用 `…good`（没有就用 6.2 的"没有存档"结果）的内容，`S.readOnly = true`，`save()` 不写；首页和练习页顶部提示条「这次练习存不下来，请家长看一下」（`--warn`）。家长区给两个出口：「导出读不了的存档」（复制原文给维护的人）→ 导出后出现「删掉它，腾出空间」，删掉后刷新即恢复正常保存。**任何情况下都不自动覆盖原主存档。**
- **好存档不被坏数据覆盖**：写 `…good` 前比较点亮格子总数（秒答 + 技能），比现有 `…good` 少了 10 个以上就不覆盖，家长区提示「进度比昨天少了很多，备份没有更新」。

### 6.5 迁移测试
1. v2 预览存档（没有 `skills`）载入 v3 → 秒答颜色数不变、错题全部 `src = speed`、`skills` 为空、`placedAt` 为空（会摸底）。
2. 预览里技能升到淡黄 → 重新载入 → 仍是淡黄；同时 v1 有新进度 → 秒答显示 v1 的。
3. 上线首启三种情况：预览键正常 / 不存在 / 读不了 → 秒答都来自 v1；技能分别是带来 / 空 / 空 + broken 有原文；再次启动不再读预览键和 v1。
4. 预览键里有不认识的编号 → 上线后被丢掉，其余照常。
5. 正式版首启后，预览页（模拟旧标签页）启动、回到前台、收到存储变化三种时机 → 都停止写入并显示 12f。
6. v3 导出 → 导入 → 秒答和技能颜色数、错题数一致；预览期导入只改秒答以外的部分。
7. v3 备份交给 v1 导入 → 不报错、秒答颜色数一致（Playwright 打开根目录 `index.html#test`，写测试键）。
8. 主存档损坏：有 `good` → 恢复、`broken` 有原文；没有 `good` → 走"没有存档"；复制失败 → 主键原样、`readOnly`、`save()` 不写；导出并删除 `broken` 后恢复正常保存。
9. 点亮格子数比 `good` 少 10 个以上 → `good` 不被覆盖。
10. 技能错题不出现在秒答错题本分组和秒答角标里，反之亦然；两道不同数的数线错题是两条，复习出原来的数。
11. 编号无重复：从 `LEVELS` 和秒答 Boss 键规则生成全部秒答键，与 17 个技能的全部编号放进一个集合比数量。

## 7. 异常处理

| 情况 | 怎么触发 | 孩子看到什么 | 进度 |
|---|---|---|---|
| 切后台 / 来电 / 锁屏 | `visibilitychange` 隐藏 | 回来：暂停卡片「休息好了吗？」+「继续」；10 分钟计时暂停 | **还没作答的题**：不记录，继续后重新出（看数重新闪），不算慢。**已判完、正在显示答案的题**：先记录，继续后出下一题 |
| 横竖屏切换 | 转成竖屏 | 「把手机横过来」；练习中同时暂停，规则同上 | 同上 |
| 存不了进度（写入报错） | 隐私限制、空间满 | 首页顶部提示条（`--warn`）「这个浏览器暂时存不了进度，练习照常」；家长区写原因和「先导出备份」 | 本次在内存里，关页面会丢 |
| 无痕浏览 | Safari 无痕模式（写入不报错，关标签就丢） | 无法可靠检测；家长区常驻一句「请不要在无痕模式下用」 | — |
| Safari 7 天不打开可能清数据 | 放假、出门 | 沿用 v2：超过 7 天没备份，首页右上角小字提醒；家长区显示 `persist()` 申请结果 | 靠备份兜底 |
| 存档读不了 | 解析失败或缺 `cards` | 见 6.3 | 原文另存，不覆盖 |
| 正式版已上线、旧预览页还开着 | 见 6.2 | 12f「新版已经上线了」+「去正式版」 | 旧页停止写入 |
| 脚本出错 | 全局 `error` / `unhandledrejection` | 全屏兜底页「哎呀，卡住了」+「重新打开」；小字给家长看出错信息 | 每题都已存 |
| 跨午夜练习 | 23:59 开始，00:01 结束 | 无感 | 按**开始那一刻**的日期（`P.day`）记录 |
| 连点 / 误触 | 反馈期间乱点 | 无反应 | 判题后 0.8 秒内锁住输入 |
| 返回手势 | 从屏幕左边缘右滑 | 见跳转表 | 不离开页面 |
| 另一个页面也开着 | 另一页写了本页正在用的进度键或笔迹键（预览期再加 `speedmap.v1`），`storage` 事件按键名过滤 | 12b「另一个页面也开着，这一页先停一下」+「在这里继续」 | 两页不互相覆盖 |
| 改了系统日期（往回调） | 今天早于上次记录 | 无感 | 不升级、不降级；错题到期按新日期算 |
| 旧脚本配新页面 | 手机缓存 | 4 个脚本都带 `?v=N` + 指纹测试 | — |
| 题目生成不出来 | 题型条件过严 | 用预设兜底题 | — |
| 今天没有可排的题 | 所有格子都深红、没有到期错题 | 今日练习只出熟练段（已牢固的格子随机交错复习），照常 10 分钟 | — |

颜色规则：提示条 `--warn`，错误 `--bad`，合格 / 绿旗 `--ok`；**四档熟练度色只表示熟练度**（品牌规范第 2 节）。

## 9. 验收标准

- **学习效果**：`tools/sim-engine.js` 改为调用真实 `engine.js` 后重跑，三种孩子的主指标和护栏不差于风险验证记录（强 ≤ 45 天、一般 ≤ 55 天、弱 ≤ 75 天；每天 ≤ 10.5 分钟；在学技能 ≤ 7 天不出现；练完后剩下的到期错题一般孩子 ≤ 5 道）。
- `npm test` 全绿，新增测试覆盖：
