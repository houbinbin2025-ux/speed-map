## 1. 意图与指标
见 `意图-v3.md`。本版推动**主指标**：19 个理解技能全部牢固（深红）的练习天数。**护栏**：每天 ≤ 10 分钟独立完成；练完后剩下的到期错题 ≤ 5 道；在学技能 ≤ 7 天不出现。**先行指标**（2 周内看）：每周新点亮格子数、每天用时中位数。

## 2. 做什么 / 不做什么
**做**
- **今日练习**：首页一个大按钮，系统排好 10 分钟（复习 → 学新的 → 熟练 → 有余力再学新的），跨技能交错出题。
- **首次摸底**：约 3–5 分钟，会的直接点亮，不让孩子从头做已经会的。
- **19 个理解技能**（看数 4、分合 5、数位 2、比大小 4、数线 4），秒答地图的各级也接进同一张技能图谱。
- 首页改为"岛"：展示所有技能组的进度，可点进去自由加练。秒答地图作为岛上的一块，**保持 v2 全部功能**。
- 秒答进度在 v1 / 预览 / 正式三处**按格子取高合并**，任何一处的练习都不丢；上线后同步写回 v1，回滚不丢进度。
- 补齐现有缺口：切后台暂停、出错兜底页、存档损坏不覆盖 + 每日好存档、返回手势、多标签页、日期倒退不升级。
- 家长区周报（意图卡的指标）。

**不做（推迟）**：故事题、模式规律（v4）；钟表、人民币（v5）；图形空间（线下积木）；新技能的 Boss 关；打印版新地图。

## 3. 孩子怎么用

### 3.1 路径
1. **第一次**：首页 →「开始」→（第一道手写题前）笔迹校准约 2 分钟 → **摸底**（顶部「看看你已经会什么」，最多 5 分钟 / 40 题）→ 结果页「你已经会了这些！」（亮起的格子闪一下）→ 今日练习，**当天总时长按 10 分钟算**（校准和摸底的时间计入，剩多少练多少）。摸底中途关掉，下次接着测。
2. **每天**：首页 = 岛 + 大按钮「开始今天的练习」→ 练到 10 分钟（顶部时间进度条，不显示倒计时数字；中途关掉再开，按今天已练的接着算）→ 结算 →「去贴 1 颗珠子」→ 首页。
3. 练满 10 分钟或今天没有可练的了，大按钮变成「今天练完啦！」，下面小按钮「再练一会」。
4. **自由加练**：岛上点技能组 → 技能组地图 →「练这个」。

### 3.2 今日练习怎么排（= `engine.js` 的 `session`）
时间预算 10 分钟，依次：
1. **复习**（最多 5 分钟）：到期错题，到期早的先出。
2. **学新的**（3 分钟）：前置都学会、自己还有灰格子的技能，同时最多 2 个；**一天最多开始 3 个从没练过的技能**；每个技能第一次出现前放一张「学一学」示范卡（摸底判为"会"的技能不放）。复习段结束后还剩 **> 10 道**到期错题 → 今天跳过这一段。
3. **熟练**：今天能升级的格子 → 已学会没牢固的格子（颜色低的、最久没练的先）→ **深红格子的维持复习**（距上次练习满 7 / 14 / 30 / 60 天，答对一次间隔往后推一档，答错回到 7 天并进错题本）。
4. **有余力再学新的**：前面都做完还有时间，而且这次合格率 ≥ 80%、没有到期错题 → 回到"学新的"继续，直到 10 分钟。
5. 都没有可练的 → 提前结束，算今天练完。

**出题规则**
- 题型格子被选中出多题：理解题型 3 题、秒答题型 5 题（秒答 L3 / L4 沿用 v2 的"一天 5 次"），和别的题交错铺开，不连着出。
- 一次练习里同一张卡最多 2 次，同一题型最多 6 次。
- 同一技能尽量不连续超过 3 题（只剩 1–2 个技能可出时除外）。
- 学新的时（格子还是灰色）答错**不进错题本**，下次学新的时继续出；学会以后再错才进。
- 一次练习按**开始那天**的日期记录（跨午夜不拆）。

**格子怎么升级**（只升不降、一天最多一级、淡红到深红隔 ≥ 3 天、日期往回调不升）
| 格子 | 规则 |
|---|---|
| 卡（一道固定题） | 合格 1 次升一级。灰 → 淡黄只要 1 次是有意的：卡数多（看数 31、分合 45），错题本兜底，下一级要另一天再证明 |
| 理解题型 | 最近 8 次（可跨天）合格 ≥ 7 次升一级；升级当天的作答不计入下一级；升级后重新数 |
| 秒答题型（L3 / L4） | 同 v2：同一天合格 5 次 |

**合格标准（先对后快）**
| 技能 | 灰的时候 | 淡黄以后 |
|---|---|---|
| 看数、数位、数线 | 对（数线：误差小于合格范围） | 同左，不计时 |
| 分合 | 对 | 对且在限时内（同秒答公式：3 秒 + 写数字用时 × 答案位数） |
| 比大小 · 点选 | 对 | 对且 ≤ 2 秒（从能点那一刻算） |
| 比大小 · 前后数 | 对 | 对且在限时内（同上公式） |
| 秒答 | 同 v2：一开始就要"又对又快" | 同 v2 |
- **错题复习过关** = 这个格子当前阶段的合格标准；对但慢 = 留原档明天再来（同 v2）。
- **「再看一次」**（看数）：用了以后答对 = 记作练过、不升级；答错照常进错题本。

**首次摸底（= `engine.js` 的 `placement`，对标 ALEKS 的简化版）**
- 按 看数 → 分合 → 数位 → 比大小 → 数线 的顺序测；秒答已有进度，不测。
- 每组的技能按难度排成一条链：**先测最难的**，再二分往下找。每次测 3 题，**错一题就提前结束这次**。
- 3 题全对：这 3 道题的格子点亮淡黄；这一组里比它简单的技能标为"会"（不放示范卡、照常从灰开始学，通常一次就过）。**不跨组推断**。
- 上限 40 题 / 5 分钟；只点亮，不让已亮的变灰。家长区可「重新摸底」。

**自由加练（技能组地图「练这个」，12 题）**
- 和今日练习同一套升级、错题、出题上限规则；时间计入当天用时统计，**不计入**今日练习的 10 分钟和贴珠子。
- 前置没学会的技能也可以练（家长或孩子主动选），第一次照样先放示范卡。

### 3.4 每种题长什么样（横屏，同 v2 布局：左题目、右作答；比大小例外）
| 技能 | 题目 | 作答 | 答错时的图解 |
|---|---|---|---|
| 看数 | 图案闪现 1.5 秒后消失（家长区可调 1 / 1.5 / 2.5 秒）；左下「再看一次」 | 手写 | 重新显示图案 + 数字；十格框按 5 一组标出：「5 和 2，是 7」 |
| 分合 | **分合图**：上面一个圆是整体，下面两个圆是部分，空着的圆要写；缺数 / 过十用算式，空格画方框 | 手写 | 十格框画出两部分（7 个实心点 + 3 个空格） |
| 数位 | 几根十条（每根 10 格）+ 几个散方块 / 「47 里有几个十？」 | 手写 | 十条和方块旁边标出数字 |
| 比大小 · 点选 | **整屏两张大卡片，数字就写在卡片上**（不分左右栏，孩子直接点大的那个数）；每张 ≥ 300×140 点 | 点卡片 | 两个数放到小数线上，大的在右边亮起：「74 在 47 的右边，74 大」，3 秒后自动下一题 |
| 比大小 · 前后数 | 「比 37 多 10 是 □」 | 手写 | 数线上从 37 跳到 47 |
| 数线 | 「把旗子插到 **7** 的位置」；线长约 760 点，两端距安全区 ≥ 24 点，只标两端（0—100 任意加标 50） | 手指在线上下 60 点内按下出现红旗（画在手指上方），可拖动，抬手停 1.2 秒自动提交；屏幕左右边缘 20 点内不接收触摸 | 正确位置插绿旗，箭头标出差多远：「再往右一点」 |

**「学一学」示范卡**（具体 → 图形 → 抽象）：3–5 秒自动动画演示怎么想（例：5 个圆点分成 2 个和 3 个，再变成分合图），下面大按钮「我知道了」。

**防乱点**（比大小点选）：最近 5 道点选题错 ≥ 3，或连续 3 题都在 0.4 秒内作答 → 「慢一点，看清楚再点」（2 秒后自动消失）；这次练习剩下的点选题，数字出现 1 秒后才能点，2 秒限时从能点那一刻算。

**孩子看到的字**
| 情况 | 文字 |
|---|---|
| 卡第一次合格 | 「✓ 对了！点亮了」 |
| 题型合格、还没升级 | 「✓ 对了！」 |
| 题型升级 | 「✓ 点亮了！」 |
| 淡黄以后，对且快 | 「⚡ 又对又快！」 |
| 淡黄以后，对但慢 | 「✓ 对了 · 再快一点就能升级」 |
| 不计时的合格 | 「✓ 对了！」（数线：「很接近！」） |
| 答错 / 不会 | 图解 + 「记住它，下次再来」 |
- 技能组地图上的题型格子显示一行小字「最近 8 次对了 6 次」。

| 12c 出错兜底 | 重新打开 → 整页刷新 → 首页 | 不动作 |
| 12f 新版已上线 | 「去新版」→ 跳到正式地址 | 不动作 |

**返回手势实现（"哨兵"写法）**：孩子**第一次点任何按钮时**用 `history.pushState` 压一条只带标记的记录（浏览器可能跳过"没有点击就压入"的记录；启动时 `history.state` 已有标记就不重复压）；不改地址，`#test` 不受影响。右滑触发 `popstate` → 按**当前页**查上表"返回"列处理 → 立刻再压回一条。页面切换本身不压记录。验收：真机在练习中、首页各连续右滑 5 次都不离开；万一离开，进度每题已存，回来刷新到首页（写进改动说明）。

### 6.1 存哪

### 6.2 秒答进度三处合并：按格子取高（只升不降，所以取高永远安全）
- 合并规则 `mergeCards(a, b)`：每个编号取 `lv` 高的那份（同 `lv` 取 `seen` 多的）；Boss 通关取并集；`log` 按日期合并。错题本不合并（只在 v2 / v3 里有）。
- **预览期**：每次启动读 `speedmap.v1`，和预览键里的秒答部分**按格子取高合并**（今日练习里练出来的秒答进步不再被冲掉）；**不写 v1**（v1 还是孩子的正式版）。
- **上线期首启**（没有 `speedmap.v2`）：①秒答 = v1 和预览键按格子取高合并；②预览键能读 → 带过来秒答以外的全部（不认识的编号丢掉）；不存在 → 从空开始（会摸底）；读不了 → 原文存进 `…broken`，从空开始，家长区提示；③写入 `speedmap.v2`，记 `migratedFromV1At`。
- **上线期每次启动**：仍然读一次 `speedmap.v1` 按格子取高合并（防止还开着的旧 v1 标签页写进去的练习丢掉）；**每次保存时把秒答部分按 v1 的格式同步写回 `speedmap.v1`**（也是取高合并）。这样回滚到 v1，v1 看到的就是最新的秒答颜色（**回滚不丢秒答进度**；理解技能和错题本在 v1 里本来就没有，回滚后留在 `speedmap.v2`，再上线时还在）。
- **旧页面**：上线时 `/v2/index.html` 换成自动跳转到正式地址；v3 预览页在启动、回到前台、收到存储变化时，发现 `speedmap.v2` 已存在 → 停止写入，显示 12f。
- **导入**：按格子取高合并，不整份覆盖（旧备份不会把新进度退回去）；家长区另给一个「整份替换（会覆盖）」放在折叠里。
- **向下兼容**：v3 备份导入 v1 不报错（已核实：v1 只检查 `cards` 是对象）。

### 6.3 存档读不了
主存档解析失败或缺 `cards`：
1. 原文复制到 `…broken`。
2. `…good` 能读 → 用它恢复，家长区提示「存档读不了，已恢复到 *某月某日* 开始练习时的样子，之后的练习没有了」。
3. 没有可用的 `…good` → 按 6.2 的"没有存档"路径。
4. 第 1 步复制失败（空间满）→ **只读运行**：内存里用 `…good`（没有就用 6.2 的"没有存档"结果），`S.readOnly = true`，`save()` 不写；首页和练习页顶部提示条「这次练习存不下来，请家长看一下」。家长区：「导出读不了的存档」→ 导出后出现「删掉它，腾出空间」→ 删掉后刷新即恢复正常保存。**任何情况下都不自动覆盖原主存档。**
- **好存档不被坏数据覆盖**：写 `…good` 前比较点亮格子总数，比现有 `…good` 少 10 个以上就不覆盖，家长区提示；家长主动"清空"或"整份替换"后重置这个比较基准。

## 7. 异常处理

| 情况 | 怎么触发 | 孩子看到什么 | 进度 |
|---|---|---|---|
| 切后台 / 来电 / 锁屏 | `visibilitychange` 隐藏 | 回来：暂停卡片「休息好了吗？」+「继续」；10 分钟计时暂停 | **还没作答的题**：不记录，继续后重新出（看数重新闪）。**已判完、正在显示答案的题**：先记录，继续后出下一题 |
| Safari 在后台把页面关掉 | 回来是整页刷新 | 回到首页；再点开始，按今天已练的秒数接着算 | 每题已存 |
| 横竖屏切换 | 转成竖屏 | 「把手机横过来」；练习中同时暂停，规则同上 | 同上 |
| 存不了进度（主存档写入报错） | 隐私限制、空间满 | 首页顶部提示条（`--warn`）「这个浏览器暂时存不了进度，练习照常」；家长区写原因、各键大小和「先导出备份」 | 本次在内存里，关页面会丢 |
| 无痕浏览 | 写入不报错，关标签就丢 | 无法可靠检测；家长区常驻一句「请不要在无痕模式下用」 | — |
| Safari 7 天不打开可能清数据 | 放假、出门 | 沿用 v2：超过 7 天没备份，首页右上角小字提醒；家长区显示 `persist()` 申请结果 | 靠备份兜底 |
| 存档读不了 | 解析失败或缺 `cards` | 见 6.3 | 原文另存，不覆盖 |
| 新版已上线、旧页面还开着 | 见 6.2 | 12f「新版已经上线了」+「去新版」 | 旧预览页停止写入；旧 v1 页写的由 v3 合并 |
| 脚本出错 | 全局 `error` / `unhandledrejection` | 全屏兜底页「哎呀，卡住了」+「重新打开」；小字给家长看出错信息 | 每题都已存 |
| 跨午夜练习 | 23:59 开始，00:01 结束 | 无感 | 按开始那天记录 |
| 连点 / 误触 | 反馈期间乱点 | 无反应 | 判题后 0.8 秒内锁住输入 |
| 返回手势 | 从屏幕左边缘右滑 | 见跳转表 | 不离开页面 |
| 另一个页面也开着 | 另一页写了本页正在用的进度键或笔迹键（`storage` 事件按键名过滤） | 12b「另一个页面也开着，这一页先停一下」+「在这里继续」 | 两页不互相覆盖 |
| 改了系统日期（往回调） | 今天早于上次升级 | 无感 | 不升级、不降级 |
| 旧脚本配新页面 | 手机缓存 | 4 个脚本都带 `?v=N` + 指纹测试 | — |
| 今天没有可练的 | 都深红、没到期 | 提前结束，算练完 | — |

颜色规则：提示条 `--warn`，错误 `--bad`，合格 / 绿旗 `--ok`（这三个是页面现有颜色，补进品牌规范第 2 节）；**四档熟练度色只表示熟练度**。
