# 说明书 · 家长「错题分析」（F 模块，2026-11-09）

> 意图和原型：`docs/原型/错题-家长视角/审查.md`、`index.html`。Ben 11-09 确认方向（「可以的，就先这样」）。
> 档位：内部工具（Ben 本人用），逻辑稳，视觉沿用家长区现有样式。对标：原型里家长 30 秒想知道的五件事。
> 数据：`docs/方案-错题数据字段.md`（`wrongs / hist / mistStat / stats.mn / mp`，v130 起 B 接入后开始记录）。
> 本说明书只管家长页。孩子的「错题宝箱」简化归谁做，等中控定。

## 1. 入口和位置
- 家长区新增一格「错题分析」，放在「这周练得怎么样」后面。格子里一句概况（本周新增、今日待复习），一个按钮「查看错题分析」。
- 点开是新页 `#mistp`（和能力观察 `#habit` 同一种做法）：顶栏「返回」+ 标题「错题分析」+「近 14 天」，内容单列滚动，最宽 760 px 居中。家长区不翻译（`i18n.js` 的 SKIP 加 `#mistp`）。
- 统计全部在新文件 `v2/mistview.js`（纯函数，node 可测）；页面只负责画。

## 2. 时间窗
- 本周 = 今天往前 7 天（含今天）；上周 = 再往前 7 天。
- 「近 14 天」= 本周 + 上周，用于错因比例和典型错法。

## 3. 哪些错题上页
- 题库里还有这道题（`K.ITEM[m.uid]` 存在），秒答下架的（`m.out`）不上。
- 还没学会的（`due !== null`）全部上；已学会的（`due === null`）只上近 14 天学会的（看 `m.pd`，没有就看 `m.last`）。
- 家长手选难度导致暂停的（`E.mistOn` 为假），照样列出，状态写「暂停」，页面顶部加一句「另有 N 道错题因难度设置暂停复习」。

## 4. 分组和排序
- 类别 = A 的 `K.mistCat(m.uid)`，找不到归「其他」。类别内按状态（今日复习 → 复习中 → 暂停 → 已学会）、再按错几次从多到少。
- 竖式不单独分组（F 11-08 定）。原计划在「写的」列标「竖式」，但记录里不分设备，手机上的同一题型是横式，标了会错，所以不标。
- 类别排序：关注分高的在前，「在好转」和「记录不全」排最后。关注分 = 近 14 天（写错 + 2 × 不会 + 0.5 × 慢）+ 还没学会的道数。同分按 `K.MIST_GROUPS` 的顺序。

## 5. 每个类别显示什么
- 名称、状态标签、一行概要：「N 道 · 共错 N 次 · 已学会 N 道」（错几次缺记录的题按 1 算，并写「至少」）。
- 错因比例条：近 14 天 `hist` 里「写错 / 不会 / 慢」的条数；三种都是 0 时不画条。
- 状态标签（一个类别一个，按顺序判，先命中先用）：
  1. 记录不全：近 14 天这一类一条 `hist` 都没有，且没有已学会的题。
  2. 在好转：近 7 天没有写错和「不会」，且（有已学会的题，或有题过了至少 2 次复习）。
  3. 需要讲解：「不会」≥ 近 14 天条数的一半。
  4. 速度慢：慢 ≥ 一半。
  5. 写错较多：其他情况。
- 典型错法（有才显示，一类最多一句）：近 14 天的写错里——
  - 写的数和正确答案只差 1，且 ≥ 2 次、≥ 写错次数一半 →「写错多为差 1」；
  - 减法题写的正好是两数之和 →「减法算成了加法」；加法反过来 →「加法算成了减法」。
- 明细表：题目（`R.mistLabel`）| 写的（最近一次写错或「不会」；口答写「口答」；没记录写「--」；带秒数时写「12 · 9 秒」）| 正确（答案）| 状态（今日复习 / 复习中 N/5 / 暂停 / 已学会；错 ≥ 2 次加一行「错 N 次」，记录不全加「记录不全」）。

## 6. 页面最上面
- 一句结论（自动生成）：
  - 没有错题 →「近 14 天没有错题」。
  - 否则取前 2 个不是「在好转 / 记录不全」的类别：「主要卡在「A」（需要讲解）和「B」（写错较多）」；没有这样的类别 →「错题都在好转」。
  - 再接趋势：本周新增比上周少 N →「本周新增错题较上周少 N 道」；多 →「多 N 道」；一样 →「与上周持平」；没有新增记录（`mn` 全无）→ 不写。
- 四个数：
  - 本周新增：本周 `stats[日].mn` 之和，下面写「较上周 ▲/▼ N」；14 天都没有 `mn` 记录显示「--」。
  - 今日复习：`E.dueMistakes(S, 今天)` 的道数（和孩子看到的一致）。
  - 反复错：上页、还没学会、`wrongs ≥ 2` 的道数。
  - 本周学会：本周 `stats[日].mp` 之和，对比同上。
- 建议（最多 3 条，按类别排序取前 3 个有建议的）：
  - 需要讲解 →「「A」：先陪做 1–2 道，讲清思路，再让孩子独立做」
  - 写错较多 →「「A」：会做但易错，提醒写完检查一遍」
  - 速度慢 →「「A」：会做但不够快，正常练习即可，不需要讲」
  - 在好转、记录不全 → 不出建议。
- 页面最下面：口径说明（不会 / 写错 / 慢 / 反复错 / 学会 / 记录不全 各一行）。
