# 意图卡 + 方案 · 秒答时间按空空实测校准（B 主模块，2026-11-09，门 0–2 草稿，交中控）

> 派单：交接 `B-派单-秒答时间校准.md`。现状：`docs/说明书-秒答时间.md`、`docs/秒答时间分类-改动说明.md`（11-08 已按难度分 7 类，但全是估计值）。

## 一、门 0 · 意图卡
**Ben 原话**：「很多题目都使用了同一个时间维度，容易将一些本来费时的变成时间总是不够，一些简单的，其实只是会，也显示秒答。这个要修正。」

**我理解的诉求**
1. 秒答要代表「熟到不用想」，而不是「会做、时间也来得及」。简单题现在的线太松，空空慢慢算也能拿秒答。
2. 费时的题线太紧，空空已经很熟了也拿不到，这对他不公平，也打击积极性。
3. 闪电秒答要真是「比平时快很多」才给，不能因为线松就一天顶满 20 次。

**指标（上线 2 周后看，数据就是这次开始记的逐题用时）**
| 指标 | 目标 |
|---|---|
| 简单题型（口算卡、短题）的秒答率 | 比改前降（改前估计 70–90%，见 §三） |
| 费时题型（多位笔算、读题题）的秒答率 | 比改前升，熟练题型稳定在 50–70% |
| 闪电占秒答 | 30–40%，每天顶到 20 次上限的天数 ≤ 1/7 |
| 已有奖励、下架、点亮 | 一个不回收（只往前生效） |

## 二、门 1 · 方案研究
| 做法 | 来源 | 借鉴什么 |
|---|---|---|
| XtraMath：每题固定限时 6 秒，可调成 3 秒，付费版可调 1.5 / 2 秒；超时答对记「对但慢」 | ✅ 官方支持页、术语表 | 「对但慢」和「秒答」分开记，我们已经这样做 |
| XtraMath：同一题连续 3 次限时内答对算掌握 | 🔍 竞品文章转述，官方未写明 | 我们「累计 3 次秒答下架」同一思路 |
| Reflex：每日目标按答对题数，不按单题时间 | ✅ 官方页 | 不适用（我们要按时间判熟练） |
| 研究：流利度标准随孩子自己的书写速度定，约为写数字速度的 2/3 | ✅ Stein 等 1997（Rocket Math 引） | 我们已按空空测到的写字速度给写字时间；这次再把「想的时间」也按他自己定 |
| 研究：「自动化」常用 2–3 秒以内，个别研究 1 秒 | ✅ 综述 | 作绝对下限的参照，免得「自己一直慢」也算熟 |

**结论**：成熟产品要么一刀切固定秒数（XtraMath），要么不看时间（Reflex）。按孩子自己的速度定、再夹在绝对上下限里，是两者折中：既不会对慢的孩子一直不公平，也不会因为「他平时就慢」把慢答当熟练。

## 三、方案（技术细节 B 定）
### 3.1 先开始记逐题用时（第 1 步，已做，v139）
- **定稿（11-09，中控拍板两步走；存储按 F《F-逐题用时-存储要求.md》，键名见交接 `B-给F-逐题用时键名.md`）**：`S.ftime = {技能编号: [倍数, …]}`，主存档顶层可选字段，版本号不变。
- 倍数 = 想的时间 ÷ 估计想的时间，两位小数；想的时间 = 实际用时 − 读题 − 写字（和秒答线同一个用时、同一组参数，`K.thinkRatio`）。按技能而不按题型记：口算卡每张最多秒答 3 次就下架，按卡永远攒不够；同技能里每张卡、每道笔算估计不同，所以存倍数。比读题写字还快记 0.05，超过 10 倍（走神）不记。
- 每技能最多 10 条，最旧在前（`E.noteThink`，写入前顺手洗掉坏值）。
- 只记：答对、不是再来一次、没看提示、不是口答。摸底、Boss、老流程不记。
- 体积：满载约 141 个技能 × 10 条，测试上限 12KB（`tests/ftime.test.js`）。合并、读档清洗归 F。

### 3.2–3.3 秒答线、闪电线（第 2 步，已做，v142）
定稿见 `docs/说明书-秒答时间校准.md` §2（倍数口径改为「(用时 − 写字) ÷ 估计的读题 + 想」；简单类只紧不松、按全类最快那部分定尺子；难类只松不紧；范围按估计值算，不用类范围；闪电 = 技能自己第 25 百分位，C 11-09 对齐）。门 2 模拟结果见 `docs/秒答时间校准-改动说明.md`。

### 3.4 只往前生效
- 已有的秒答次数、点亮、下架、碎片、宝石都不动；只影响以后的判断。

## 四、门 2 · 最大风险验证（做法）
| 风险 | 怎么验证 |

| 2. 个人化以后，每个题型的秒答率都被拉到 50% 左右，「熟」失去绝对意义 | 绝对下限（类下限、估计值 × 0.5）挡住；用 `tools/sim-gems.js`、`sim-engine.js` 按「强 / 一般 / 弱」三种孩子模拟改前改后：简单题秒答率降、难题升，三种孩子都不会卡死 |
