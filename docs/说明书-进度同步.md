# 说明书 · 家长一键同步（手机 ↔ iPad）

> 2026-11-08 Ben 拍板选 B「家长一键同步」，中控派单，C 暂代 F 实施。分支 `mod-c-sync`。

## 一、要解决什么
空空在手机（Safari）和 iPad（App）上都练，两边进度各存各的。家长要能不联网、不登录，把两边合成一样。

## 二、怎么用（家长）
1. 在一台设备的家长区点「发送进度」→ 系统分享面板 → 隔空投送到另一台。
2. 另一台点「接收进度」→ 在「文件」里选这个文件 → 自动合并，显示一句结果。
3. 反过来再做一次，两边就一致了。

## 三、规则
| 项 | 规则 |
|---|---|
| 文件内容 | 就是现在的「导出进度」文字（进度 JSON + 顶层 `gems`），文件名 `空空数学岛-进度-YYYY-MM-DD.json`。数据结构不改 |
| 发送 | 能分享文件（`navigator.canShare({files})`）就调起系统分享；不能就下载文件（iPad App 里下载会被外壳拦掉，改为提示用「导出进度」）。发送成功或下载都算一次备份（`S.lastBackup`）；取消分享不算 |
| 接收 | `<input type=file>` 选文件 → 和「导入进度」同一条路（`mergeText`，只增不减）：格子、错题、伙伴、碎片、伙伴罐都合并 |
| 同一份收两次 | 不翻倍：第二次结果是「已合并：没有新内容」 |
| 旧格式 | 没有 `gems` 的旧导出文字也能收：进度合并，碎片不动 |
| 结果一句话 | 「已合并：新点亮 3 格、升级 1 格、新错题 2 道、错题进度更新 1 道、碎片 +40 个」，没有的项不写；全都没有写「已合并：没有新内容」（不说「两边一致」：只收一次只能保证本机不比对方少）；碎片按个数；碎片没合并补「；碎片没有合并」 |
| 上次同步 | 上次「接收进度」成功的时间，只存本机（键 `<进度键>.sync`），不进进度、不进备份；按日历天算几天前，坏值和未来时间当没同步过 |
| 提醒 | 超过 3 天没同步，家长区「进度备份」那一栏多一行黄字；首页和孩子看到的地方不提示。从没同步过（只用一台设备）不提醒 |
| 英文 | 家长区不翻译（项目规矩：家长区、题库预览、崩溃页不翻译），不加英文 |

## 四、合并口径（沿用导入进度，只改错题一处）
- **错题（11-08 审查后改，「导入进度」同样生效）**：同一道错题两边都有，取最近一次复习的那条（`last` 晚的，每次复习都会更新）；同一天取已过关的，再取过的关多的。原来以本机为准，互发后一边已过关、另一边还在复习，iPad 会一直出已经过关的题。
- 每格档位取高、达标日期合并；伙伴并集最多 4 只；思维地点、秒答次数、到过的级别取大。
- 碎片背包按种类取大、伙伴罐余额取大（中控 11-08 已接受：旧文件会让花掉的宝石回来）。

## 五、验证
- `tests/sync.test.js`：互发一致、收两次不翻倍、旧格式、结果文案、文件名、几天前。
- `tools/e2e/e2e-sync.py`：两个浏览器当两台设备，家长区真点发送 / 接收；不能分享时退回下载；超过 3 天的提示只在家长区。
- iPad App（iOS 模拟器）：系统分享面板能弹出、能「保存到文件」；「接收进度」能打开「文件」选到文件并读出内容。**隔空投送模拟器里没有，没验证，要真机。**
