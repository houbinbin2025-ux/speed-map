# 说明书 · v5 空空的家（门 3）

## 1. 意图与指标
见 `意图-v5-家.md`。主指标不变；先行：主动打开天数、从家进入练习的次数；护栏：家里时间 ÷ 练习时间 ≤ 20%、练习分钟数和错题积压不变差。

## 2. 做什么 / 不做什么
**做**：点岛上的家进屋；奖状墙（25 张，称号 + 会动画面，记牢 = 附魔）；伙伴图鉴（38 只，可带 4 只回家）；战利品箱；矿物柜；木箱（矿石累计）；可摆放道具（36 件）；下一个目标告示牌；旧进度补发。
**不做**：商店、货币、抽奖、连续打卡、排行、家里的计时玩法。排课、判题、升级、题库一律不动。

## 3. 孩子怎么用
岛 → 点家（或「家」按钮）→ 小人走进去 → 屋内。有战利品箱就点开 → 收好 → 看新奖状 → 收好。拖着逛、点东西看；没得到的显示条件和「去练这一块 / 开始今天的探险」。出门：点门或「回到岛上」。练完结算页：有新奖励时主按钮是「回家打开」。

## 4. 页面清单
屋内（`#house`）；右侧卡片（道具 / 目标 / 告示牌 / 矿物柜 / 木箱）；奖状大图；图鉴；开箱层。异常页沿用 v2（存不了进度提示条、出错兜底页）。

## 5. 跳转表
| 页 | 出口 | 系统返回手势 |
|---|---|---|
| 屋内 | 门 / 回到岛上 → 岛；去练这一块 → 岛上走过去 → 练习；秒答 → 秒答地图 | 回岛 |
| 卡片 / 奖状 / 图鉴 / 开箱 | 关闭回屋内 | 先关这一层 |
| 结算页 | 回家打开 → 屋内；回到岛上 → 岛 | 沿用 |

## 6. 数据
新字段 `S.home = {ore, got: {编号: 日期}, loot: [编号], place: {道具: 位置}, pets: [技能编号] | null, sec, go}`；`S.stats[日].home` 记当天在家的秒数。键仍是 v2 存档。
- **全部奖励由进度算出**，第一次打开把已达成的放进战利品箱（日期 = 这一天）。
- **只增不减**：得到过的记在 `got`，之后统计变少（如统计满 400 天被裁掉）也不收回。
- **旧数据**：没有 `S.home` 的存档自动补；累计天数同时看 `S.stats` 和 v1 的 `S.log`。矿石从上线起累计，旧的补不了。
- **累计天数**：当天练满 5 分钟或今天的题做完才算一天（`S.stats[日].done`，引擎记）；秒答（含 v1 旧日子）不进时长，答满 10 题算。
- **备份**：整份导入照搬；合并导入 `got` 取并集（日期取早）、矿石取大、已开过的不再进箱。
- **回滚**：旧代码不认 `S.home`，原样留在存档里不影响进度；再升回来继续用。
- 迁移测试：`tests/home.test.js`。

## 7. 异常处理
| 情况 | 处理 |
|---|---|
| 存不了进度 | 家照常看，提示条沿用；奖励下次重算，不丢 |
| 存档损坏 | 沿用 v2 恢复流程；家从恢复后的进度重算 |
| 切后台 / 来电 | 家没有计时玩法；回来原样。切走时补记停留秒数 |
| 横竖屏 | 竖屏沿用全局「把手机横过来」；转回重新布局 |
| 跨午夜 | 奖励日期按进门时的 `today()`，只影响显示 |
| 连点 / 边拖边点 | 移动 ≥14 像素不算点；开箱、关闭可重复点 |
| 脚本出错 | 沿用全局兜底页；进度已存 |
| 多标签页 | 沿用 v2 的「另一个页面打开着」处理 |
| 新增技能没有对应生物 | 按编号落到已有生物，不报错；测试会拦 |

## 8. 速度预算
进屋（点到画面）≤ 300 毫秒（不含走路动画）；拖动 ≥ 55 帧；奖励计算 ≤ 20 毫秒。用 Playwright 和 Ben 真机验证。

- 秒答的「打败 / 驯服」是比喻，不要求真打过秒答地图的 Boss 关；守关怪用自己的名字（果冻王等），和秒答地图的 Boss 分开。
