# 说明书 · 每道题都有秒答时间（Ben 11-07）

> 档位：可交付（空空每天在用）。对标：数学事实流畅度的通行标准（约 3 秒内提取才算自动化）。

## 意图
Ben：「答题，每个题目需要有一个秒答的时间，思考很久的答案就是不熟悉。秒答才是习得。整个体系里都要有这个思维。」

## 规则
1. **每道题一个秒答时间** = 想的时间（按题型定）+ 读题时间（题面每个汉字 0.4 秒，英文日多给一半）+ 写字时间（答案每位按孩子测到的写字速度，口答和点选没有）。表在 `v2/skills.js` 的 `FAST_THINK`，秒答卡沿用原来的 3 / 5 秒。**新增题型必须定时间**，`tests/fasttime.test.js` 会拦。
2. **只有秒答才算学会**：取消「先对后快」和「不计时」，所有题从灰格起：
   - 点亮、升级、最近 8 次合格、错题过关、维持复习、摸底判为会，都要求又对又在时间内。
   - 累计秒答（含闪电秒答）3 次算熟练、不再出（Ben 11-07，原 4 次）。三四年级新题原来「答对就计次」的特例取消。防刷靠这条加「每题每天只有第一次作答给碎片」；Ben 要留一点可刷的空间当动力，所以 3 次之内反复赚是允许的。
3. **慢不是错**：答对但超时不进错题宝箱，不扣分，格子不动，这类题后面继续出（格子没亮就还会排到，到期的明天再来，深红的维持复习从头计）。
4. **孩子看得见**：题目上方一条秒答时间条，走完变空，不打断、不催、不发声。超时答对提示「这次 8 秒，秒答要 5 秒内」。点喇叭听题后重新计时。全系统统一叫「秒答」，不再说「又对又快」。
5. **奖励跟着快慢走，答对就有（Ben 11-07）**：每次答对都有 1 块矿石。碎片：慢答 1 个小碎片；秒答 = 原规则（小或中）+ 1 个小碎片；闪电秒答（用时不到秒答时间 60%，时间条蓝色段）再 + 1 个中碎片，一天最多 20 次（小碎片单独炼不出宝石，给小的等于没奖励）。挑战题要秒答才算过，慢答给矿石和 1 个小碎片。口答照旧不给碎片。
6. **家长看得见**：结算页显示秒答几道；能力观察加秒答率；题库页显示每个题型的秒答时间。

## 不变
- 进度只升不降：以前慢答点亮的格子、已下架的题都不动。
- 存储结构不变，无需迁移；只在每日习惯记录加一个计数 `f`。
- 例外：思维地点（天平桥等）不计时，原意图是「这些题是想出来的」。这条和 Ben 的新要求有张力，已提请 Ben 拍板。

## 风险与验证
- 时间定得太紧 = 孩子永远升不上去。时间表是估计值，等真实数据后只改这一张表。`tools/sim-engine.js` 模拟看开级节奏不卡死。
- 回归：`npm test`，`tools/e2e/` 全量，`overflow.py`（时间条不占布局）。
