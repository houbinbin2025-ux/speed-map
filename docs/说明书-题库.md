# 说明书 · 独立题库 + 家长区查看（门 3，2026-10-29）

> 意图见 `意图-题库.md`。档位：**可交付**（进家长区、进正式版）；对标：可汗学院的家长 / 老师端「技能 → 练习题」列表、ALEKS 的知识点题库，都是「题目是数据，按知识点分类，可预览」。

## 1. 现在的问题（实测）
- 理解技能 19 个：卡 76 张是写死的，但 **23 个题型**（比大小、缺数、过十、数位、前后数、数线、分合求整体）是代码里 `rint()` 现拼数字，没有清单。
- 秒答 L3 / L4 的 **24 个题型**也是现拼（拒绝采样，`core.js`），L1 / L2 的 200 张卡由几个循环算出来。
- 现拼的问题：难点靠运气。例：`cmp:t:100` 随机两个两位数，十位相同（最难的 47 和 43）只占约 10%；`cmp:t:p1` 跨十（39 多 1）只占约 10%；没人能检查。
- 家长区看不到任何题。

## 2. 「够学会」的标准（五条，全部写成测试）
| # | 标准 | 怎么查 |
|---|---|---|
| S1 覆盖 | 每个技能先列出它的**难点情况**（例：前后数 = 普通 / 跨十），每种情况题量 ≥ 下限；有标签的题型每道题都归进一种情况（不许有"其他"）；**比大小点选题大数在左、在右各占 40%–60%**（一直点一边升不了级）；秒答抽样题型里第二个数的个位每个允许的值都出现、难点题（凑成整十 / 被减数是整十 / 得数是一位数）≥ 20 道 | 测试 |
| S2 数量 | 卡技能 = 全部情况一张不少；题型：能出的题 ≤ 400 种 → **全收**；> 400 种 → **按情况分层抽 120 道**。出题是**发牌**：一个题型把池里的题一轮发完才重洗，同一轮不重复；**发到哪一张记在存档里**（`S.decks`，每个题型只存种子和位置几个数），关掉重开接着发（一天最多 6 道，120 道约 20 天才轮一遍，背不出答案） | 测试对比"能出的全部"和题库；发牌测试 |
| S3 答案对 | 每道题的答案用测试里另写的算法重算一遍，必须相同 | 测试 |
| S4 有讲解 | 每道题都能画出题面和答错图解；每个理解技能都有示范卡（固定例题）；**秒答 20 以内及以上的进位、退位题答错时有一句讲解**（先凑整十 / 先退到整十 / 两位数先算几个十），讲解里的得数逐题核对 | 测试 + `overflow.py` 摆一遍 |
| S5 不越级 | 每道题都在原来的出题规则以内（例：L4 至少一个数 > 50、进位题真的进位）；**秒答 L3 加法要先学会 L2 的进位加法，L3 减法要先学会 L2 的退位减法**（28 + 5 用到 8 + 5；原来只要求数位） | 测试用原来的规则逐题检查 + 前置测试 |

> 为什么 400 / 120（10-29 审查后改；原来 120 / 60 是按"家长翻得过来"定的，砍掉了 121–400 种的题型的覆盖面）：400 以内全收只多几十 KB，家长页按情况分组折叠；120 道配合发牌，一个题型要连练约 20 天才重复。

**每个技能还写三行给家长看的话**：学什么（一句）、怎样算学会（按格子规则自动生成，不手写）、怎么教（示范卡 + 答错图解说什么，一句）。

**抽样方法**（只在生成题库时用一次，`tools/build-bank.js`）：每种情况内用**固定种子打乱**后取（每次跑结果一样）；比大小先按"一对数"抽，再轮流决定大数在左还是右。10-29 审查实测"排好序等间隔取"会和排序撞拍（十位相同的全是相邻数、L4 加数永远没有 3/6/8、大数 52/60 在右），已弃用。

**改题规则**（写在 `bank.js` 的 meta 里）：卡和题型的**编号只增不删**；**卡的题目不许改**（要改就换新编号，否则孩子在这张卡上的颜色变成另一道题的）；题型的题目池可以增删——不在池里的旧错题照常复习，家长页单列"题库外的旧错题"。

## 4. 代码怎么接（改动最小）
- `bank.js` 先加载（浏览器 `window.BANK`，node `require`）。
- `core.js`：L1 / L2 的卡从 `BANK.speed` 读，L3 / L4 题型的 `gen` 改成从题库池里抽；编号、`fast`、题目字段都不变。
- `skills.js`：卡从 `BANK` 读；题型的 `gen(r)` 改成从题库池里**发牌**（`core.js` 的 `deal`，理解和秒答共用）。题目字段和**字段顺序**都和原来一样（错题键 = `编号|JSON.stringify(q)`，顺序一变就成两条），快照测试逐字比对原来生成器出的错题键。示范卡改用固定例题（`K.example`）。
- 没有加载 `bank.js` 时 `core.js` 直接报错（出错页），不会带着空编号表跑到清理未知进度。
- `engine.js`、排课、升级、判题：**不改**。
- `tools/bump-version.js`、`tests/page.test.js`、`tools/e2e/e2e3.py` 的文件清单加上 `bank.js`；页面按 bank → core → ink → skills → engine → render 加载（测试检查），6 个脚本同一个 `?v=`。
- 正式版 v1（根目录 `index.html`）是内联脚本，不受影响。

## 5. 家长区「题库」页
- 入口：家长区**第一块**「题库」，6 个板块按钮直接进对应板块（长按齿轮 → 点板块 → 看题目，3 步）。
- 页面：左边板块（看数 · 分合 · 数位 · 比大小 · 数线 · 秒答），右边这个板块的技能，一个技能一张卡：
  - 名称 · 学什么 · 怎样算学会 · 前置（标出学会 ✓ / 摸底会还没练 / 还没学会）· 题量 · 每个题型「能出 N 种，题库收 M 道」· 孩子现在的进度（卡：亮了几张；理解题型：当前颜色 + 最近 8 次对几次；秒答题型：今天合格几次 / 5 次）
  - 点「看题目」展开：按难点情况分组的题目小格（如「骰子 3」「47 和 43 谁大」「□ + 3 = 7」）；**卡**按孩子的颜色上色，**题型**整体一个颜色、每道题只标红点（在错题本里）；最后单列「题库外的旧错题」。列表顶上有颜色图例。
  - 点一道题：弹出**孩子看到的题面**（同 `render.js`）+ 答案 + 「答错时看到」的图解；右上关闭。
- 只看不改；孩子进不来（入口仍在齿轮长按 2 秒后）。

## 6. 迁移与测试
- 改代码前，把现在所有卡的编号和题目、所有题型的编号写进 `tests/fixtures/items-before.json`（快照）；改完测试比对：**卡编号和题目一个不差，题型编号一个不差，题库每道题的字段和原来出的题一样**。
- 旧错题：从快照里每个题型用原来的生成器抽 200 道当"旧错题"，新版本都能画出题面、判对判错。
- S1–S5 各一条测试；页面测试：题库页的 id 都在、`$('xx')` 都有。
- 验收：家长区 → 题库 → 每个板块 → 展开 → 点题预览，932×430 和 667×375 截图；孩子视角走查（新上下文审查员）照常跑一遍今日练习，确认出题没变坏。
