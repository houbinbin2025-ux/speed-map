## 1. 一句话

每道错题多记两样：**错了几次**（`wrongs`）和**最近 5 次出错的经过**（`hist`：哪天、写了什么、用了几秒、哪种错）。另外按技能记一份**累计数**（`S.mistStat`），因为题型错题每种只留 3 道，旧的会被删，单题上的次数会丢。每日统计加两个数（新增、过关）给「比上周好还是差」用。

**只记录，不改排课**：复习间隔、过关、`passes`、`due` 的算法一个字不动。

## 2. 新字段

### 2.1 每道错题 `S.mistakes[key]` 上（秒答格式和题型格式都加）

| 字段 | 类型 | 含义 | 什么时候写 |
|---|---|---|---|
| `wrongs` | 整数 ≥ 1 | 这道题累计错了几次（写错 + 不会） | 新进错题本 = 1；已在本里又错（练习中或复习时）+1 |
| `hist` | 数组，最多 5 条，旧的在前 | 最近几次出事的经过 | 每次 `wrongs` +1 时记一条；复习时「对但慢」也记一条 |

`hist` 每条：`{d, k, w, s, o}`

| 键 | 含义 | 取值 |
|---|---|---|
| `d` | 日期 | `'YYYY-MM-DD'`（和 `added`、`last` 同一格式） |
| `k` | 哪种 | `'w'` 写错 · `'d'` 点了「不会」· `'s'` 答对但慢（只在复习时记） |
| `w` | 孩子写了什么 | 字符串，最长 16 字；不会 / 口答 / 拿不到时为 `null` |
| `s` | 用了几秒 | 一位小数，封顶 120；拿不到时省略 |
| `o` | 口答 | 口答模式下为 `1`（家长点「答错了」，没有孩子写的内容），否则省略 |

- `w` 的写法由 B 定：手写 = 识别结果（`'22'`）；选择题 = 选中的选项文字；数线 = 点的数；竖式 = 最后一行的数。写不出就 `null`，家长页显示「--」。
- 看过提示（`peeked`）、再来一次（`retry`）、摸底、Boss 的错**不记**，和能力观察同一口径。
- 过关（`due` 变成 `null`）时 `hist` 剪到只留最后 1 条，控制体积。

### 2.2 按技能的累计数 `S.mistStat`（新的顶层键）

```
S.mistStat = { <技能 id>: {w, d, s, p, last} }
```

| 键 | 含义 |
|---|---|
| `w` | 写错次数累计 |
| `d` | 「不会」次数累计 |
| `s` | 复习时「对但慢」次数累计 |
| `p` | 过关（复习满 5 次）的错题道数累计 |
| `last` | 最近一次变化的日期 |

- 键用**技能 id**（只增不删，最稳）。家长页要的「知识点类别」在显示时由技能映射出来，映射表归 A（`skills.js`），以后改类别不用迁移数据。
- 题型错题被 `TYPE_MIST_MAX` 删掉时，这里的数不减。

### 2.3 每日统计 `S.stats[日]` 加两个数

| 键 | 含义 |
|---|---|
| `mn` | 当天新进错题本的道数 |
| `mp` | 当天过关的道数 |

给「新增错题较上周」「本周过关」用。旧日子没有这两个数，算「--」，不算 0。

## 3. 迁移（硬约束 2：先迁移、后升级）

- **版本号不变（`v: 2`）**：全是可选字段，旧代码读到新存档会忽略，新代码读到旧存档当「没记录」。所以 v1 回滚、手机和 iPad 版本不一致时都不出错。
- **不补旧数据**：旧错题没有 `wrongs` / `hist`，显示「--」，不猜成 1（猜错了家长会误判「只错过一次」）。旧错题再错一次时从 `wrongs: 1` 开始记，家长页对这种题标「记录不全」。
- **读档清洗**（加进 `core.upgrade`）：`wrongs` 不是正整数 → 删掉；`hist` 不是数组 → 删掉；数组里坏的条目丢掉、超过 5 条剪掉；`w` 超过 16 字截断；`mistStat` 不是对象 → 删掉，里面不是数字的字段删掉。坏字段只丢这个字段，错题本身和排课不受影响。

## 4. 导入合并（`core.importMerge`）

现在是同一道错题整条以本机为准。改成：整条仍以本机为准（`passes`、`due` 不动），只有新字段合并：

| 字段 | 合并规则 | 为什么 |
|---|---|---|
| `wrongs` | 两边取大 | 同一份备份导两次不翻倍 |
| `hist` | 两边并起来，按 `d+k+w+s` 去重，按日期排序留最后 5 条 | 同上 |
| `mistStat` 每个数 | 两边取大；`last` 取晚的 | 同上；和习惯记录「按天取大」一致 |
| `stats[日].mn` / `mp` | 按天取大 | 同上 |

整份替换（`importText`）照旧以备份为准，只过一遍清洗。

## 5. 体积

- 每条 `hist` 约 40 字节，一道错题最多 5 条 ≈ 200 字节；过关后剪到 1 条。
- 按现有性能测试的规模（460 道错题、全部复习中）估：约 90 KB，加上 `mistStat`（技能约 300 个 × 40 字节 ≈ 12 KB），总共约 100 KB。Safari 单站约 5 MB，现在整份进度 ⏳ 待实测（实施时在测试里量一份 460 道满记录的导出文字，定上限）。

## 6. 接口（F 写，B 调）

```js

C.noteMistake(S, key, ev, day)   // ev = {k: 'w'|'d'|'s', w, s, o, skill}：写 wrongs / hist / mistStat / stats.mn
```
