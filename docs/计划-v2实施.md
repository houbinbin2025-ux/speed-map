# 秒答地图 v2 · 实施计划

> 依据：`说明书-v2.md`（R1–R3 修订）+ `原型/`（11 页，Ben 10-25 确认）。
> 执行方式：主会话按任务顺序 TDD（测试先行）实施；完成后新上下文独立审查（中档）。

**目标**：在 `v2/` 预览路径做出横屏手写 + 错题本版本，线上根目录 `index.html` 不动。
**架构**：纯逻辑与界面分离——`v2/core.js`（题库、升级、限时、错题本、配题、迁移，零 DOM）+ `v2/ink.js`（笔画分组、数字识别，零 DOM）+ `v2/index.html`（界面）。两个 js 用同一写法：浏览器里挂到全局，node 里 `require`，测试直接跑。
**技术**：原生 HTML/CSS/JS，无框架、无 CDN；测试 `node --test tests/`（Node 26 自带）。

## 任务

### 任务 1 · core：题库、升级、限时
- 搬 v1 的 LEVELS / UNITS / TYPES（id 生成规则一字不改，保证旧进度对得上）。
- `tryUp(S,id,t)`：同 v1（只升不降、一天最多一级、淡红→深红隔 ≥3 天）。
- `fastLimit(unit, mode, speed)`：口答 = `unit.fast`；手写 = `unit.fast + (speed||1000) × 答案位数`。
- 测试：L1 共 110 张、L2 共 90 张、各 12 种题型；id 样例 `3+4`、`L3:add1c`；tryUp 四种路径；手写限时 10 以内一位数 = 3000（speed 缺省）、`13` = 3000+2×speed。

### 任务 2 · core：存储键与迁移（说明书「数据迁移」5 场景）
- `keysFor({preview,test})`：正式 `speedmap.v2` / 预览 `speedmap.v2.preview` / 测试 `speedmap.v2.test`；笔迹 `speedmap.ink`（测试 `speedmap.ink.test`）。
- `upgrade(v1)`：补 `v:2`、`mistakes:{}`、`lastBackup:0`。
- `loadState(storage, ctx, now)`：
  - 预览：地图进度每次从 v1 只读复制；错题本与设置取预览键；不写 v1。
  - 正式：有 v2 用 v2；没有则从 v1 迁移一次、记 `migratedFromV1At` 并立刻写 v2；之后不读 v1。
- 测试（内存假存储）：①预览期 v1 新进度下次可见 ②预览练习后 v1 字节不变 ③正式首启颜色数 = v1 ④迁移后改 v1 不影响 v2 ⑤迁移只一次 ⑥导出导入（含换入口）颜色数一致 ⑦坏备份被拒。

### 任务 3 · core：错题本 + 配题合并
- 错题条目 `{key, uid, a, op, b, ans, L, passes, due, added}`；key：一题一卡 = 卡 id，题型 = `uid|a op b`。
- `addMistake(S, q, t)`：新建或重置 `passes=0, due=t+1`。
- `reviewMistake(S, key, result, t)`：`fast` → passes+1，满 5 = 已掌握，否则 due = t + [1,2,4,7,15][passes]；`slow` → 原档、due = t+1；`wrong` → passes=0、due = t+1。
- `dueMistakes(S, t, L, series)`：到期、同级别、按系列过滤、到期早的在前。
- `buildDaily(S, pool, t, {rnd, mistakes})`：按说明书 B 节——错题先占 ≤4 → 练习中（每个 2 次，奇数名额最后一个 1 次）填到 8 → 余量再给错题；一题一卡错题已在练习中 → 附到该卡第 1 次出现；题型错题所属题型在练习中 → 顶替该题型一次出题；补满只用非难题；开头结尾 3 道会的；同题隔 3 道。
- 测试：错题 0/3/6/10 × 练习中 0/1/3/5 的 16 种组合，断言难题题次 ≤8、错题不重复、补满不含难题、系列过滤、间隔表 1/2/4/7/15、慢了留原档、错了回第 1 档、同一错题当天不再到期。

### 任务 4 · ink：分组与识别
- `groupStrokes(strokes)`：按横向范围重叠合并（「4」「5」多笔归一组；「1」「3」分两组），左→右。
- `recognize(strokes, templates)`：每组给前两名候选与距离；`confident` = 第二名距离 / 第一名 ≥ 1.25（实测后调）。
- `addTemplate(store, digit, pts)`：每个数字最多 15 个，新换旧。`medianSpeed(samples)`：校准时每个数字书写用时的中位数。
- 测试：用程序生成的 0–9 标准笔画做模板，加抖动/缩放/平移后仍认对 ≥95%；「13」分 2 组、「4」(两笔) 1 组；模板上限 15。

### 任务 5 · 界面 `v2/index.html`
按原型 11 页：首页（级别、三练习、错题本角标、地图、预览条、N 天没备份、齿轮长按 2 秒进家长区）→ 校准（0–9 各 3 遍、记速度）→ 作答（左题右板、擦掉/不会 56 点、停 0.9 秒 / 位数不够 1.5 秒自动提交、新笔重计时）→ 答对 / 4b / 识别确认（只问没把握那位、重写）/ 答错描一遍（描一笔或 3 秒；连错第 2 道起不描）→ 结算（错题行）→ 错题本 → 家长区（备份天数、导出导入进度与笔迹、口答模式、清空两步、重新校准）→ 竖屏提示。长按 1 秒结束（填充进度，点一下提示「按住不放」）。去掉 `apple-mobile-web-app-capable`；申请 `navigator.storage.persist()`；保留 `#test` 测试条（快进日期）。
