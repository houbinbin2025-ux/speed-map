# 单双日语言 · 改动说明（2026-11-06）

## 改了什么
- 孩子看到的字：**单日英文、双日中文**。31 号和 1 号连着都是英文。开页面和每次回到岛上时判断；练习中途跨天不切。
- 家长区加了一个勾选项「单日英文、双日中文（今天：英文/中文）」，默认勾选。取消后一直中文，立刻生效，刷新后保持。
- 家长区、题库页、题库预览和崩溃页永远中文；`#test` 的测试条也不翻译。
- 英文日题目、讲解、示范卡、错题标签全部是英文，朗读读英文（`html lang=en`，朗读代码按它选语音）。英文按同龄母语孩子的正常用词写，和中文题同等难度。
- 名字都是原创英文：Kongkong Math Island、Void Dragon、Shadow King、Deep Guard、Lava Land、Sky End 等。

## 怎么做的
新文件 `v2/i18n.js`：业务代码里的中文一个字不改。屏幕上的字按「字典 → 模式」换成英文，原文另存，切回中文时还原。判题读题目数据，存档存的也是原始数据，都不经过这一层。中文日这一层不工作。
英文比中文长，`v2/index.html` 加了一组只在英文日生效的样式（`html[lang=en]` 开头）。

## 可能影响什么
- 页面打开时，语言定下来之前先不画（避免闪中文）；脚本解析完才显示，中文日也一样。
- 新增孩子能看到的文字要在 `v2/i18n.js` 加英文，否则英文日会露中文（记入 `I18N.misses`，测试会拦）。
- 全部现有回归脚本的种子设了 `bilingual=false`，它们测的是中文界面。

## 怎么退回
- 只想关掉：家长区取消勾选。
- 代码退回：删掉 `v2/i18n.js`、它的 script 标签、`i18n-wait` class 和样式、`html[lang=en]` 样式、`applyLang`、`biBox` 相关几行、`fitBody` 里的 `I18N.flush()`。进度不受影响：存档只多一个 `settings.bilingual` 字段，旧版会忽略它。

## 没验证什么
- 没上 iPhone / iPad 真机：Safari 的英文语音、英文字体下的真实折行没看过，回归用的是桌面 Chromium。
- 朗读只验证了按钮的朗读文字变成英文、`html lang=en`，没听过声音。
- 英文措辞没有母语者或老师审过；`Number Bonds`、`regrouping` 是英语区小学常用词，空空是否熟悉要 Ben 看。
- 崩溃页走的是原逻辑，没有单独造崩溃验证。
